第 18 课 · py-018

函数基础：把代码打包成菜谱

知识要点

1. 为什么需要函数——重复代码的救星
没函数：查 3 个病人体温要写 3 遍判断。有函数：把逻辑打包成"菜谱"，喊一声就用。 
def 发热判断(体温):          # 定义：写下"体温分诊"SOP
    if 体温 >= 38:
        return "发热"
    else:
        return "正常"

print(发热判断(38.5))        # 调用：按 SOP 处理 38.5 → 发热
print(发热判断(37.0))        # → 正常
医生类比：def = 写标准操作流程（SOP）；参数 = SOP 的输入栏；return = SOP 的输出；调用 = 按 SOP 处理某个输入。
2. 函数结构四件套
def 函数名(参数):       # ① def + 名字 + (参数) + 冒号
    """功能说明"""      # ② 函数体（缩进！）
    return 结果         # ③ return = 把结果交出来

结果 = 函数名(实参)      # ④ 调用
3. ⚠️ return vs print——别搞混
def 加一(x):
    print(x + 1)        # 只是显示，结果丢了

def 加一返回(x):
    return x + 1        # 交出值，能继续用

加一(5)                  # 输出 6，但结果烂在肚子里
y = 加一返回(5)          # y = 6，能继续算
print(y * 2)             # 12
核心：print = 写给自己看（显示）；return = 递给别人用（可继续处理）。没有 return 的函数返回 None。
一句话总结：函数 = 把重复逻辑打包成菜谱（SOP）——def 写流程、参数收输入、return 交结果；print 是显示、return 是递交，没 return 返回 None。

练习题

基础题

1
基础def 关键字

函数定义用哪个关键字开头？

A. function　　B. def　　C. func　　D. define

参考答案
B。Python 用 def（define 的缩写）定义函数。
2
基础return 取值

下面代码输出什么？

def 平方(x):
    return x * x
print(平方(4))

A. 4　　B. 16　　C. 报错　　D. 不输出

参考答案
B。平方(4) 返回 4×4=16，print 显示 16。
3
基础无 return

下面代码输出什么？

def 打招呼(名字):
    print("你好", 名字)
结果 = 打招呼("张三")
print(结果)

A. 你好 张三 / 你好 张三　　B. 你好 张三 / None　　C. 你好 张三　　D. 报错

参考答案
B。打招呼 里只有 print 没有 return → 返回 None。第一行"你好 张三"是函数内 print 的输出，第二行 None 是 print(结果)。
4
基础交出结果

想定义一个函数把两个数相加并"交出结果"继续用，用哪个？

A. print(a + b)　　B. return a + b　　C. def a + b　　D. 都不行

参考答案
B。return 才交出值；print 只是显示。

进阶题

5
进阶return 中断

下面代码输出什么？

def 检查(x):
    if x > 0:
        return "正数"
    return "非正数"

print(检查(5), 检查(-3))

A. 正数 非正数　　B. 正数 正数　　C. 非正数 非正数　　D. 报错

参考答案
A。return 会立即结束函数——x>0 时走第一个 return，后面的代码不再执行。检查(-3) 跳过 if 块，落到第二个 return。
6
进阶返回值参与运算

下面代码输出什么？

def 温差(a, b):
    return a - b

print(温差(38.5, 37.0) * 2)

A. 1.5　　B. 3.0　　C. 2.0　　D. 报错

参考答案
B。温差(38.5, 37.0) 返回 1.5，再 ×2 = 3.0。return 的值能继续参与运算——这就是"递交"的意义。

运用题

7
运用分诊函数

写一个分诊函数：体温 ≥38 返回"急"，≥37.2 返回"普通"，否则"慢"。然后调用它给 38.5 和 36.8 分诊。

提示：def + if/elif/else + return；调用两次分别打印。

参考答案
def 分诊(体温):
    if 体温 >= 38:
        return "急"
    elif 体温 >= 37.2:
        return "普通"
    else:
        return "慢"

print(分诊(38.5))   # 急
print(分诊(36.8))   # 慢
自查要点：函数把"分诊规则"封起来——以后规则改了（比如 38→38.5）只改函数内部一处，所有调用自动生效。这就是函数最大的价值：改一处，处处生效。
8
运用病历格式化（填空）

写一个函数，输入姓名和体温，返回格式化字符串"张三：38.5度"（填空）：

def 病历行(姓名, 体温):
    return ____   # 填：返回 "姓名：体温度" 格式的字符串

print(病历行("张三", 38.5))

提示：用 f-string 拼接，如 f"{姓名}：{体温}度"。

参考答案
def 病历行(姓名, 体温):
    return f"{姓名}：{体温}度"

print(病历行("张三", 38.5))   # 张三：38.5度
解析：return 返回 f-string 结果。函数把"格式规则"封起来——要改格式只改这一处。参数从外传进，结果从 return 递出。
