第 18 课 · py-018

函数基础：把代码打包成菜谱

知识要点

1. 为什么需要函数——重复代码的救星
没函数：查 3 个病人体温要写 3 遍判断。有函数：把逻辑打包成"菜谱"，喊一声就用。 
def 发热判断(体温):          # 定义：写下"体温分诊"SOP
    if 体温 >= 38:
        return "发热"
    else:
        return "正常"

print(发热判断(38.5))        # 调用：按 SOP 处理 38.5 → 发热
print(发热判断(37.0))        # → 正常
医生类比：def = 写标准操作流程（SOP）；参数 = SOP 的输入栏；return = SOP 的输出；调用 = 按 SOP 处理某个输入。
2. 函数结构四件套
def 函数名(参数):       # ① def + 名字 + (参数) + 冒号
    """功能说明"""      # ② 函数体（缩进！）
    return 结果         # ③ return = 把结果交出来

结果 = 函数名(实参)      # ④ 调用
3. ⚠️ return vs print——别搞混
def 加一(x):
    print(x + 1)        # 只是显示，结果丢了

def 加一返回(x):
    return x + 1        # 交出值，能继续用

加一(5)                  # 输出 6，但结果烂在肚子里
y = 加一返回(5)          # y = 6，能继续算
print(y * 2)             # 12
核心：print = 写给自己看（显示）；return = 递给别人用（可继续处理）。没有 return 的函数返回 None。
一句话总结：函数 = 把重复逻辑打包成菜谱（SOP）——def 写流程、参数收输入、return 交结果；print 是显示、return 是递交，没 return 返回 None。

练习题

基础题

1
基础def 关键字

函数定义用哪个关键字开头？

A. function　　B. def　　C. func　　D. define

参考答案
B。Python 用 def（define 的缩写）定义函数。
2
基础return 取值

下面代码输出什么？

def 平方(x):
    return x * x
print(平方(4))

A. 4　　B. 16　　C. 报错　　D. 不输出

参考答案
B。平方(4) 返回 4×4=16，print 显示 16。
3
基础无 return

下面代码输出什么？

def 打招呼(名字):
    print("你好", 名字)
结果 = 打招呼("张三")
print(结果)

A. 你好 张三 / 你好 张三　　B. 你好 张三 / None　　C. 你好 张三　　D. 报错

参考答案
B。打招呼 里只有 print 没有 return → 返回 None。第一行"你好 张三"是函数内 print 的输出，第二行 None 是 print(结果)。
4
基础交出结果

想定义一个函数把两个数相加并"交出结果"继续用，用哪个？

A. print(a + b)　　B. return a + b　　C. def a + b　　D. 都不行

参考答案
B。return 才交出值；print 只是显示。

进阶题

5
进阶return 中断

下面代码输出什么？

def 检查(x):
    if x > 0:
        return "正数"
    return "非正数"

print(检查(5), 检查(-3))

A. 正数 非正数　　B. 正数 正数　　C. 非正数 非正数　　D. 报错

参考答案
A。return 会立即结束函数——x>0 时走第一个 return，后面的代码不再执行。检查(-3) 跳过 if 块，落到第二个 return。
6
进阶返回值参与运算

下面代码输出什么？

def 温差(a, b):
    return a - b

print(温差(38.5, 37.0) * 2)

A. 1.5　　B. 3.0　　C. 2.0　　D. 报错

参考答案
B。温差(38.5, 37.0) 返回 1.5，再 ×2 = 3.0。return 的值能继续参与运算——这就是"递交"的意义。

运用题

7
运用分诊函数

写一个分诊函数：体温 ≥38 返回"急"，≥37.2 返回"普通"，否则"慢"。然后调用它给 38.5 和 36.8 分诊。

提示：def + if/elif/else + return；调用两次分别打印。

参考答案
def 分诊(体温):
    if 体温 >= 38:
        return "急"
    elif 体温 >= 37.2:
        return "普通"
    else:
        return "慢"

print(分诊(38.5))   # 急
print(分诊(36.8))   # 慢
自查要点：函数把"分诊规则"封起来——以后规则改了（比如 38→38.5）只改函数内部一处，所有调用自动生效。这就是函数最大的价值：改一处，处处生效。
8
运用病历格式化（填空）

写一个函数，输入姓名和体温，返回格式化字符串"张三：38.5度"（填空）：

def 病历行(姓名, 体温):
    return ____   # 填：返回 "姓名：体温度" 格式的字符串

print(病历行("张三", 38.5))

提示：用 f-string 拼接，如 f"{姓名}：{体温}度"。

参考答案
def 病历行(姓名, 体温):
    return f"{姓名}：{体温}度"

print(病历行("张三", 38.5))   # 张三：38.5度
解析：return 返回 f-string 结果。函数把"格式规则"封起来——要改格式只改这一处。参数从外传进，结果从 return 递出。
第 19 课 · py-019

函数参数进阶：位置 / 默认 / 关键字

知识要点

1. 位置参数——按顺序对号入座
def 开医嘱(药名, 剂量, 频次):
    print(f"开医嘱：{药名} {剂量}，{频次}")

开医嘱("阿司匹林", "100mg", "每日一次")   # 按位置一一对应 ✅
开医嘱("每日一次", "100mg", "阿司匹林")   # 位置错 = 药开错 ❌
底层逻辑：实参按位置依次传给形参。顺序错不报错但结果错——比报错更危险。
2. 默认参数——不填就用默认值
def 开医嘱(药名, 剂量, 频次="每日一次"):   # 频次有默认值
    print(f"{药名} {剂量}，{频次}")

开医嘱("阿司匹林", "100mg")             # 频次不填 → 默认
开医嘱("阿司匹林", "100mg", "每日两次")   # 填了 → 覆盖
规则：默认参数必须放在无默认参数后面。def f(a=1, b) 报错！
3. 关键字参数——点名传参（顺序随意）
开医嘱(频次="每日一次", 药名="阿司匹林", 剂量="100mg")   # ✅ 顺序随便

开医嘱("阿司匹林", 剂量="100mg", 频次="每日一次")       # ✅ 位置在前关键字在后
开医嘱(药名="阿司匹林", "100mg")                        # ❌ 关键字在前位置在后 → 报错
规则：位置参数在前，关键字参数在后。
一句话总结：位置按顺序对号入座、默认不填用兜底（必须在无默认后面）、关键字点名传参顺序随意（位置在前关键字在后）。

基础题

1
基础默认参数

下面代码输出什么？

def 打招呼(名字, 问候语="你好"):

打招呼("张三")

A. 你好 张三　　B. 张三 你好　　C. 报错（少参数）　　D. 你好

参考答案
A。问候语有默认值"你好"，不填就用默认。
2
基础调用报错

下面哪个调用会报错？

def f(a, b=1, c=2):
    print(a, b, c)

A. f(5)　　B. f(5, 6)　　C. f(a=5, c=6)　　D. f(b=6, 5)

参考答案
D。关键字参数在前、位置参数在后 → 语法错误。规则：位置在前，关键字在后。
3
基础关键字乱序

下面代码输出什么？

def 计算(x, y, z):
    return x + y - z
print(计算(z=10, x=5, y=3))

A. -2　　B. 8　　C. 报错　　D. 12

参考答案
A。关键字参数按名字对应：x=5, y=3, z=10 → 5+3-10 = -2。顺序随意但名字要对。
4
基础定义报错

下面哪行定义会报错？

A. def f(a, b=1):　　B. def f(a=1, b):　　C. def f(a, b, c=3):　　D. def f(a, b=1, c=2):

参考答案
B。默认参数必须在无默认参数后面。a=1 有默认却在 b（无默认）前面 → 报错。

进阶题

5
进阶混合调用

下面哪个调用不报错？

def 医嘱(药名, 剂量, 频次="每日一次", 备注=""):
    pass

A. 医嘱("阿司匹林", "100mg", "每日两次", "餐后")　　B. 医嘱(药名="阿司匹林", "100mg")　　C. 医嘱("阿司匹林", 备注="空腹")　　D. A 和 C

参考答案
D。A 全位置传 4 个 ✅；C 位置+关键字混合（位置在前）✅；B 关键字在前位置在后 ❌。
6
进阶默认值顺序

def f(a, b=2, c=3)，调用 f(1, c=30) 后 b 和 c 分别是？

A. b=2, c=30　　B. b=30, c=3　　C. b=2, c=3　　D. 报错

参考答案
A。a=1 位置传入；c=30 关键字点名；b 没传 → 用默认 2。默认参数可以"跳过"不传，用关键字精准指定。

运用题

7
运用开医嘱函数

写函数：输入药名、剂量，频次默认"每日一次"，备注可选。然后调用：① 阿司匹林 100mg（全默认）② 二甲双胍 500mg 每日两次 餐后服用。

提示：def + 默认参数 + 关键字参数。

参考答案
def 开医嘱(药名, 剂量, 频次="每日一次", 备注=""):
    return f"{药名} {剂量}，{频次}" + (f"，{备注}" if 备注 else "")

print(开医嘱("阿司匹林", "100mg"))
print(开医嘱("二甲双胍", "500mg", "每日两次", "餐后服用"))
自查要点：默认参数让"常规医嘱"只需填 2 个参数；特殊医嘱补全 4 个。函数的灵活性来自参数设计。
8
运用缺省调用（填空）

调用 开医嘱("硝苯地平", "30mg") 时，频次和备注用什么？

提示：没传就用默认值。

参考答案
频次="每日一次"（默认），备注=""（默认）。调用时不传的参数自动用定义时的默认值——这就是"默认参数"的意义。
第 20 课 · py-020

返回值与作用域：return 多值 + 局部 vs 全局

知识要点

1. return 多个值——返回元组，可以拆包
def 查体征(体温, 心率):
    return 体温, 心率        # 逗号分隔 = 返回元组

结果 = 查体征(38.5, 90)
print(结果)                  # (38.5, 90)

体温, 心率 = 查体征(38.5, 90)   # 拆包：两个变量各接一个
print(体温, 心率)              # 38.5 90
底层逻辑：return a, b, c 返回元组 (a, b, c)。拆包 = 像 items() 遍历时"键, 值"一样一次接多个。
2. 局部 vs 全局——独立房间规则
库存 = 100                # 全局：整个程序可见

def 查库存():
    return 库存            # ✅ 能"读"全局（查医院总库存）

def 扣库存(数量):
    库存 = 库存 - 数量     # ❌ 报错！"写"全局没声明
    return 库存
规则三连：
情况结果
函数里读全局✅ 可以
函数里写全局（赋值）❌ UnboundLocalError
global 声明 + 写✅ 特批通道
3. global 声明——特批改全局
总发药量 = 0

def 发药(数量):
    global 总发药量          # 声明：我要改全局
    总发药量 += 数量

发药(10); 发药(20)
print(总发药量)              # 30
注意：尽量少用 global——好函数习惯是"参数进、return 出"，不偷偷改外面。
一句话总结：return a,b 返回元组可拆包；函数是独立房间——读全局随便读、写全局要 global（否则报错）、局部变量外面看不见。

练习题

基础题

1
基础return 多值

下面代码输出什么？

def 返回两个():
    return 1, 2
结果 = 返回两个()
print(结果)

A. 1 2　　B. (1, 2)　　C. [1, 2]　　D. 报错

参考答案
B。return 1, 2 返回元组 (1, 2)。
2
基础读全局

下面代码输出什么？

x = 5
def 函数():
    return x + 1
print(函数())

A. 6　　B. 5　　C. 报错　　D. 1

参考答案
A。只读不写 → 读全局 x=5 → 返回 6。
3
基础写全局未声明

下面代码会怎样？

x = 5
def 函数():
    x = x + 1
    return x
函数()

A. 返回 6　　B. 报错（UnboundLocalError）　　C. 返回 5　　D. x 变成 6

参考答案
B。函数内对 x 赋值 → Python 认定 x 是局部变量 → 右边读 x 时局部未定义 → 报错。写全局必须先 global 声明。
4
基础global 声明

想让函数修改全局变量，需要先在函数里写什么？

A. import　　B. return　　C. global 变量名　　D. def

参考答案
C。global 声明 = 特批通道，函数里才能改全局。

进阶题

5
进阶读改写三连

哪个不报错？

总数 = 10

A. def f(): return 总数 + 1　　B. def f(): 总数 = 总数 + 1　　C. def f(): global 总数; 总数 += 1　　D. A 和 C

参考答案
D。A 只读 ✅；C global 声明后写 ✅；B 赋值没声明 ❌。三连口诀：读可以、写要 global、声明+写成功。
6
进阶局部变量隔离

下面代码输出什么？

def 测试():
    局部 = 20
    return 局部
测试()
print(局部)

A. 20　　B. 报错（NameError）　　C. None　　D. 0

参考答案
B。局部变量只在函数内存在，函数结束后消失——外面访问报 NameError。函数 = 独立房间，外面看不见里面。

运用题

7
运用多值返回

写函数：输入体温和心率，返回"体温值、心率值、是否发热(≥38)"三个结果，然后拆包打印。

提示：return 三个值，调用时三个变量拆包。

参考答案
def 评估(体温, 心率):
    发热 = 体温 >= 38
    return 体温, 心率, 发热

体温, 心率, 发热 = 评估(38.5, 90)
print(体温, 心率, "发热" if 发热 else "正常")   # 38.5 90 发热
自查要点：一个函数返回多个相关信息，调用处拆包各归各——比分别写多个函数简洁。
8
运用全局计数器（填空）

统计发药次数（填空）：

发药次数 = 0

def 发药():
    ____         # 填：声明要改全局
    发药次数 += 1

发药(); 发药(); 发药()
print(发药次数)   # 3

提示：global 声明。

参考答案
发药次数 = 0

def 发药():
    global 发药次数
    发药次数 += 1

发药(); 发药(); 发药()
print(发药次数)   # 3
解析：全局计数器 + global = 跨函数累计状态的标准写法。但记住：能用 return 传递就别用 global。
