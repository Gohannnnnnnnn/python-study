第 18 课 · py-018

函数基础：把代码打包成菜谱

知识要点

1. 为什么需要函数——重复代码的救星
没函数：查 3 个病人体温要写 3 遍判断。有函数：把逻辑打包成"菜谱"，喊一声就用。 
def 发热判断(体温):          # 定义：写下"体温分诊"SOP
    if 体温 >= 38:
        return "发热"
    else:
        return "正常"

print(发热判断(38.5))        # 调用：按 SOP 处理 38.5 → 发热
print(发热判断(37.0))        # → 正常
医生类比：def = 写标准操作流程（SOP）；参数 = SOP 的输入栏；return = SOP 的输出；调用 = 按 SOP 处理某个输入。
2. 函数结构四件套
def 函数名(参数):       # ① def + 名字 + (参数) + 冒号
    """功能说明"""      # ② 函数体（缩进！）
    return 结果         # ③ return = 把结果交出来

结果 = 函数名(实参)      # ④ 调用
3. ⚠️ return vs print——别搞混
def 加一(x):
    print(x + 1)        # 只是显示，结果丢了

def 加一返回(x):
    return x + 1        # 交出值，能继续用

加一(5)                  # 输出 6，但结果烂在肚子里
y = 加一返回(5)          # y = 6，能继续算
print(y * 2)             # 12
核心：print = 写给自己看（显示）；return = 递给别人用（可继续处理）。没有 return 的函数返回 None。
一句话总结：函数 = 把重复逻辑打包成菜谱（SOP）——def 写流程、参数收输入、return 交结果；print 是显示、return 是递交，没 return 返回 None。

第 19 课 · py-019

函数参数进阶：位置 / 默认 / 关键字

知识要点

1. 位置参数——按顺序对号入座
def 开医嘱(药名, 剂量, 频次):
    print(f"开医嘱：{药名} {剂量}，{频次}")

开医嘱("阿司匹林", "100mg", "每日一次")   # 按位置一一对应 ✅
开医嘱("每日一次", "100mg", "阿司匹林")   # 位置错 = 药开错 ❌
底层逻辑：实参按位置依次传给形参。顺序错不报错但结果错——比报错更危险。
2. 默认参数——不填就用默认值
def 开医嘱(药名, 剂量, 频次="每日一次"):   # 频次有默认值
    print(f"{药名} {剂量}，{频次}")

开医嘱("阿司匹林", "100mg")             # 频次不填 → 默认
开医嘱("阿司匹林", "100mg", "每日两次")   # 填了 → 覆盖
规则：默认参数必须放在无默认参数后面。def f(a=1, b) 报错！
3. 关键字参数——点名传参（顺序随意）
开医嘱(频次="每日一次", 药名="阿司匹林", 剂量="100mg")   # ✅ 顺序随便

开医嘱("阿司匹林", 剂量="100mg", 频次="每日一次")       # ✅ 位置在前关键字在后
开医嘱(药名="阿司匹林", "100mg")                        # ❌ 关键字在前位置在后 → 报错
规则：位置参数在前，关键字参数在后。
一句话总结：位置按顺序对号入座、默认不填用兜底（必须在无默认后面）、关键字点名传参顺序随意（位置在前关键字在后）。

第 20 课 · py-020

返回值与作用域：return 多值 + 局部 vs 全局

知识要点

1. return 多个值——返回元组，可以拆包
def 查体征(体温, 心率):
    return 体温, 心率        # 逗号分隔 = 返回元组

结果 = 查体征(38.5, 90)
print(结果)                  # (38.5, 90)

体温, 心率 = 查体征(38.5, 90)   # 拆包：两个变量各接一个
print(体温, 心率)              # 38.5 90
底层逻辑：return a, b, c 返回元组 (a, b, c)。拆包 = 像 items() 遍历时"键, 值"一样一次接多个。
2. 局部 vs 全局——独立房间规则
库存 = 100                # 全局：整个程序可见

def 查库存():
    return 库存            # ✅ 能"读"全局（查医院总库存）

def 扣库存(数量):
    库存 = 库存 - 数量     # ❌ 报错！"写"全局没声明
    return 库存
规则三连：
情况结果
函数里读全局✅ 可以
函数里写全局（赋值）❌ UnboundLocalError
global 声明 + 写✅ 特批通道
3. global 声明——特批改全局
总发药量 = 0

def 发药(数量):
    global 总发药量          # 声明：我要改全局
    总发药量 += 数量

发药(10); 发药(20)
print(总发药量)              # 30
注意：尽量少用 global——好函数习惯是"参数进、return 出"，不偷偷改外面。
一句话总结：return a,b 返回元组可拆包；函数是独立房间——读全局随便读、写全局要 global（否则报错）、局部变量外面看不见。

第 21 课 · py-021

lambda 与内置函数：一行版函数 + 批量处理

知识要点

1. lambda——一行版函数（自动 return）
加倍 = lambda x: x * 2
        print(加倍(5))   # 10

        # 对比普通函数
        def 加倍(x):
            return x * 2
结构：lambda 参数: 表达式——不需要 def、return 关键字。像"一句话菜谱"。
2. lambda 实战：作为 sorted/max/min 的 key 参数
病人 = [{"姓名":"张三", "年龄":45}, {"姓名":"李四", "年龄":38}]
        排序后 = sorted(病人, key=lambda p: p["年龄"])
        # 按年龄从小到大排

        最高龄 = max(病人, key=lambda p: p["年龄"])
        # 找年龄最大的病人
底层逻辑：key 参数告诉 sorted "按什么规则排序"——lambda 临时写个规则，用完就丢。
3. 常用内置函数
len([1,2,3])     # 3 —— 长度
        sum([1,2,3])     # 6 —— 求和
        max([1,2,3])     # 3 —— 最大
        min([1,2,3])     # 1 —— 最小
        sorted([3,1,2])  # [1,2,3] —— 排序（返回新列表，原列表不变）
一句话总结：lambda = 一行版函数（自动 return），最常用作 sorted 的 key 参数——"临时规则用完就丢"。

A. [3,1,2] [1,2,3]　　B. [1,2,3] [1,2,3]　　C. [3,1,2] [3,1,2]　　D. 报错

参考答案
A。sorted 返回新列表，原列表不变。x 还是 [3,1,2]，y 是 [1,2,3]。
