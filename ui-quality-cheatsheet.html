大厂界面质感 · 5 招

为什么 AI 做的界面有"塑料味" · 差的就是这 5 个细节
核心结论：大厂 AI 客户端和"AI 随手搓"的差距，不在功能，在 5 个几乎看不见的细节。把这些写进提示词，AI 出的界面立刻上一个档次。
整理自 Ludi 抖音视频（扒大厂 AI 客户端源码）
五个细节
01 / 05
扔掉黑粗边框
不要用 1px solid #333 画边框分层。用 4 级微明度背景色阶，相邻两级亮度只差 1%~3%——看上去有层次，但没有一根线。
而且全站不要用纯黑 #000（刺眼）。
/* 用背景差分层，不用边框 */
:root {
  --surface-0: #0f1115;   /* 页面底 */
  --surface-1: #14171c;   /* 卡片 */
  --surface-2: #191d23;   /* 悬浮 */
  --surface-3: #1f242b;   /* 弹层 */
}
.card { background: var(--surface-1); border: none; }
02 / 05
视网膜欺骗术（暗色字重）
同样粗细的字，在深色背景上看起来更粗、更刺眼——这叫"光渗效应"（Optical Irradiation），因为亮色在白底上会向外"晕开"。
所以暗色模式的字重要比亮色模式细一档（比如 500 → 400，或 variable font 的 wght -50）。
:root { font-weight: 450; }
[data-theme="dark"] { font-weight: 400; }  /* 暗色调细一档 */
03 / 05
水墨晕染式打字
AI 流式输出时，别让字一个一个"硬蹦"出来。每个字带一点模糊渐显，像墨滴落在纸上晕开——质感立刻不同。单字约 120ms，模糊从 6px 收到 0。
.char {
  opacity: 0;
  filter: blur(6px);
  animation: inkIn 120ms ease-out forwards;
}
@keyframes inkIn {
  to { opacity: 1; filter: blur(0); }
}
04 / 05
等宽数字（治乱抖）
"思考中 13 秒"这种计时、统计、价格——普通字体每个数字宽度不同，数字一跳整行就左右乱晃。加一行 CSS 就稳了。
.timer, .price, .stats {
  font-variant-numeric: tabular-nums;
  /* 或 font-feature-settings: "tnum"; */
}
05 / 05
动效也分性格
不是所有动效都用同一条曲线。
· 拖拽：要"过阻尼"——快速到位，几乎不回弹（东西跟着手走，要跟手）
· 点赞/收藏：要"欠阻尼"——明显 Q 弹回弹（这是情绪反馈，要有弹性）
/* 拖拽：过阻尼，快到位 */
.drag { transition: transform 180ms cubic-bezier(0.2, 0.9, 0.3, 1); }

/* 点赞：欠阻尼，明显回弹 */
.like { transition: transform 420ms cubic-bezier(0.34, 1.56, 0.64, 1); }
可直接抄的提示词
给 AI 写界面前，把这段加进去
  1. 不要用 1px 边框做分层。改用 4 级微明度背景色（surface-0 到 surface-3），相邻两级亮度只差 1%~3%。全站不要用纯黑 #000。
  2. 暗色模式下字重比亮色模式细一档（如 450 → 400），避免光渗效应让字发胖刺眼。
  3. 流式输出的文字用"水墨晕染"效果：每个字从 blur(6px) + 透明渐显到清晰，单字约 120ms，不要硬蹦出来。
  4. 所有数字（计时、统计、价格）使用等宽数字：font-variant-numeric: tabular-nums。
  5. 动效分性格：拖拽用"过阻尼"（快速到位、几乎不回弹），点赞/收藏用"欠阻尼"（明显 Q 弹回弹）。
用法：把这段贴在你的需求前面，比如"【界面质感要求见下】……现在帮我做一个登录页"。AI 会照做，出来的东西立刻不一样。
