AI 界面质感 · 9 招

两个作者的"5 个细节"合并去重 · 全是纯 CSS，零成本
核心：大厂界面和"AI 随手搓"的差距不在功能，在这些几乎看不见的细节。全部是纯 CSS，加进提示词就生效。
整理自 Ludi、费纸张两条抖音视频（#vibe知识大赏）
一、分层与边框（3 招）
01
微明度色阶代替边框
不要用 1px solid #333 画边框分层。改用 4 级微明度背景色，相邻两级只差 1%~3%——有层次但没有一根线。全站避免纯黑 #000。
:root {
  --surface-0: #0f1115;  /* 页面底 */
  --surface-1: #14171c;  /* 卡片 */
  --surface-2: #191d23;  /* 悬浮 */
  --surface-3: #1f242b;  /* 弹层 */
}
.card { background: var(--surface-1); border: none; }
02
用阴影代替边框费纸张
需要"边界感"时，用极淡的多层阴影，比 1px 线自然得多——像纸片浮在桌面上，而不是被框住。
.card {
  border: none;
  box-shadow:
    0 1px 2px -1px rgb(0 0 0 / .06),
    0 2px 4px rgb(0 0 0 / .04);
}
03
同心圆角费纸张
嵌套的圆角要"同心"：内层半径 = 外层半径 − 间距。否则看起来像两块不搭的板子拼在一起。
/* 外层 20px 圆角，padding 4px
   → 内层应该是 16px（20 - 4），不是 20 */
.card     { border-radius: 20px; padding: 4px; }
.card-in { border-radius: 16px; }
二、文字（3 招）
04
等宽数字（治乱抖）
计时、统计、价格——普通字体每个数字宽度不同，数字一跳整行就左右乱晃。一行 CSS 就稳。
.timer, .price, .stats {
  font-variant-numeric: tabular-nums;
}
05
暗色模式字重调细一档
同样粗细的字，在深色背景上看起来更粗更刺眼——"光渗效应"（Optical Irradiation）。所以暗色模式的字重要比亮色细一档。
:root { font-weight: 450; }
[data-theme="dark"] { font-weight: 400; }
06
平衡标题换行费纸张
标题最后一行只剩一两个字，很难看。一行 CSS 让每行长度均衡（浏览器自动算）。
h1, h2, .title {
  text-wrap: balance;
}
三、动效（3 招）
07
水墨晕染式打字
AI 流式输出时，别让字一个一个"硬蹦"。每字带一点模糊渐显，像墨滴晕开，单字约 120ms。
.char {
  opacity: 0;
  filter: blur(6px);
  animation: inkIn 120ms ease-out forwards;
}
@keyframes inkIn { to { opacity:1; filter:blur(0); } }
08
错开入场费纸张
别让整块内容一起淡入——卡片一张张错开出现，页面立刻"活"了。用 --i 变量控制顺序。
.item {
  animation: fadeUp 400ms ease-out both;
  animation-delay: calc(var(--i) * 100ms);
}
/* 元素上写 style="--i:0" / "--i:1" / "--i:2" ... */
09
动效也分性格
不是所有动效都用同一条曲线：
· 拖拽：过阻尼——快速到位，几乎不回弹（要跟手）
· 点赞/收藏：欠阻尼——明显 Q 弹回弹（是情绪反馈）
/* 拖拽：快到位 */
.drag { transition: transform 180ms cubic-bezier(0.2,0.9,0.3,1); }
/* 点赞：明显回弹 */
.like { transition: transform 420ms cubic-bezier(0.34,1.56,0.64,1); }
可直接抄的提示词（9 条全在这里）
让 AI 写界面前，把这段贴在需求前面
  1. 不要用 1px 边框分层。改用 4 级微明度背景色（surface-0~3），相邻只差 1%~3%；全站不用纯黑 #000。
  2. 需要边界感时用极淡多层阴影，不要用边框。
  3. 嵌套圆角要同心：内层半径 = 外层半径 − padding。
  4. 所有数字（计时/统计/价格）用 font-variant-numeric: tabular-nums。
  5. 暗色模式字重比亮色细一档（如 450 → 400），避免光渗效应。
  6. 标题加 text-wrap: balance，让换行长度均衡。
  7. 流式文字用"水墨晕染"：每字从 blur(6px)+透明渐显到清晰，单字约 120ms。
  8. 列表/卡片用错开入场：animation-delay: calc(var(--i) * 100ms)。
  9. 动效分性格：拖拽用过阻尼（快速到位），点赞用欠阻尼（明显回弹）。
用法：「【界面质感要求见下】……现在帮我做一个登录页」。
比反复说"做得高级一点"有用得多——"高级"AI 理解不了，"亮度差 1-3%"它能执行。
一句话记住
分层背景差 1-3%，不用线
边界淡阴影比边框自然
圆角内 = 外 − padding
数字tabular-nums 防抖
暗色字重调细一档
标题text-wrap: balance
打字模糊渐显别硬蹦
入场错开 100ms 一张
动效拖拽硬、点赞弹
总则细节决定"贵不贵"
