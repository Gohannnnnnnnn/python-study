不是 GIF，不是视频——是一张 20 帧的雪碧图

视频里明确写了："一张 20 帧的图，不到 500KB"。原理是把 20 张画好的小猫动作拼成一张大图（sprite sheet），然后用 CSS 逐帧切换显示区域。

好处：体积小、不卡、能精确控制（想让它笑就笑，想让它闭眼就闭眼）。GIF 做不到这点——GIF 只能一播到底。

方案 A · 雪碧图（视频同款）20 帧拼一张图，CSS steps() 切帧。效果好、需要的是一张图。难点：得先有美术素材。
方案 B · SVG + JS（本 Demo）不用素材，代码画猫，眼睛实时跟随。难点：动作没 A 丰富，但零成本、可控。
方案 A：雪碧图逐帧动画

假设图是 20 帧横排，每帧 200×170：

/* 整张图 4000×170，每帧 200 宽 */
.cat{
  width:200px; height:170px;
  background:url(cat-sprite.png) no-repeat;
  background-size:4000px 170px;   /* 20 帧总宽 */
}
/* 眨眼：只播第 6-8 帧 */
.cat.blink{
  animation: blink .24s steps(3) 1;
}
@keyframes blink{
  from{ background-position: -1000px 0 }  /* 第6帧 */
  to  { background-position: -1600px 0 }  /* 第9帧 */
}

关键技巧：把 20 帧分区——0-5 待机、6-8 眨眼、9-13 看左边、14-19 闭眼。JS 只需要给元素换 class，就切换整套动作。

方案 B：眼睛跟随鼠标（本 Demo 用的）

核心就三步：拿鼠标坐标 → 算眼睛到鼠标的角度 → 把瞳孔推过去（限制最大距离，不然眼球会飞出去）。

const pupils = document.querySelectorAll('.pupil');

document.addEventListener('mousemove', e => {
  pupils.forEach(p => {
    const eye = p.getBoundingClientRect();
    const cx = eye.left + eye.width / 2;
    const cy = eye.top  + eye.height / 2;

    // 角度
    const ang = Math.atan2(e.clientY - cy, e.clientX - cx);
    // 距离：越远推得越多，但最多 6px
    const d = Math.min(6, Math.hypot(e.clientX - cx, e.clientY - cy) / 30);

    p.style.transform =
      `translate(${Math.cos(ang) * d}px, ${Math.sin(ang) * d}px)`;
  });
});

再配一句 transition: transform 140ms cubic-bezier(.34,1.2,.64,1)——瞳孔就有"弹性跟手"的感觉，不是硬邦邦跟着。

加点小心思（这三招让体验翻倍）

① 点输入框 → 它盯着你

输入框获得焦点时，让眼睛往下看（输入框在猫下方）。实现：focus 时给瞳孔一个固定的 translateY(4px)。

② 输密码 → 它闭眼

切到 .eye-closed（弯弯的闭眼线）。"我不看你密码"——这一下用户会笑出来，这就是"治愈感"的来源。

③ 登录成功 → 换成笑脸

按钮点击后换成"眯眼笑"的帧/表情。逻辑上是把 class 从 idle 切到 happy。

「在登录页顶部加一只跟着鼠标动的猫。要求：
1）用内联 SVG 画（不用图片素材），橘色圆头、两只三角耳、大眼、腮红；
2）瞳孔随鼠标移动，用 atan2 算角度，最大位移 6px，transition: transform 140ms cubic-bezier(.34,1.2,.64,1)；
3）账号/密码输入框获得焦点时，眼睛看向该输入框；
4）密码框聚焦时切换成闭眼状态；
5）点登录按钮时切"眯眼笑"；
6）尊重 prefers-reduced-motion，开启时不做跟随动画。」
