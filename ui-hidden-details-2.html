01 · 打中文不怕误发

坑长什么样

用中文输入法打「nihao」，候选框还开着（显示"你好 / 3尼豪 / 4泥嗪"），这时按回车——半截拼音直接被发了出去。用户的本意是"选第一个候选"。

大厂做法：回车前先看一眼——候选框还开着 → 回车 = 选字；候选框已关上 → 回车 = 发送。

还有第二个坑（视频里专门提了）

Safari 这类浏览器在你选完字之后，会自己再补发一次回车。所以光判断"正在 composing"不够——选完字之后的那 半秒内，多出来的那个回车也要吞掉，否则字上去了、消息也照样发出去了。

const ta = document.getElementById('input');
let lastComposed = 0;

ta.addEventListener('compositionend', () => {
  lastComposed = Date.now();          // 记下"刚选完字"的时刻
});

ta.addEventListener('keydown', e => {
  if (e.key !== 'Enter' || e.shiftKey) return;

  // ① 还在拼写/选词：回车只上屏，不发送
  if (e.isComposing || e.keyCode === 229) return;

  // ② Safari 选完字后会补发回车：半秒内的也不发送
  if (Date.now() - lastComposed < 500) return;

  e.preventDefault();
  send(ta.value);
});
一句话：isComposing 挡的是"还在选字"，lastComposed < 500ms 挡的是"选完字那一下"——两个都要，缺一个都会漏。
02 · 翻记录不被拽走

坑

AI 正在流式输出，你往上翻想重读刚才那段——新内容一来就把你拽回底部。这叫"强拽到底"，长对话里最烦人的体验。

大厂做法：贴着底才跟随，一翻就松手。而且阈值是量出来的，不是凭感觉：

距底 0.0 行自动跟随，新内容来了直接滚到底
距底 3 行不再跟随，弹出「跳至最新」
3 行内 / 1 行外中间的迟滞区，避免按钮狂闪
按钮形态半透明玻璃，浮在内容上，不占布局

const GAP_FOLLOW = 1;    // 距底 1 行以内 → 跟随
const GAP_BUTTON = 3;    // 超过 3 行 → 出按钮

scroller.addEventListener('scroll', () => {
  const gap = scroller.scrollHeight - scroller.scrollTop - scroller.clientHeight;
  const rows = gap / lineHeight;
  following = rows <= GAP_FOLLOW;
  jumpBtn.classList.toggle('show', rows > GAP_BUTTON);

function append(text){
  const atBottom = following;      // 追加前记一次，别在 DOM 变高后判
  list.append(makeMsg(text));
  if (atBottom) scroller.scrollTop = scroller.scrollHeight;
}
最常写错的一行：在 append() 之后才判断"是否在底部"——那时 scrollHeight 已经变了，永远判成"不在底部"，跟随就失效。要在追加之前记录状态。
03 · 边框只准套一层

坑

卡片一圈框、里面气泡一圈框、工具栏再一圈框、按钮还一圈框——套娃 4 层，又土又挤。眼睛要穿过四道线才能读到内容。

大厂规矩写得很死：从外往里只穿过 1 层框；层次靠底色和留白，不靠线；按钮不画边框，鼠标放上去才变一下底色。

左边：套娃 4 层 ／ 右边：单层 + 底色

左边数一下：从外到按钮要穿过 4 条线。右边只有最外 1 条。

两个配套细节（视频里专门圈出来的）

① 线的位置决定会不会跳：普通画法把线画在格子外面，选中时线变粗——下面的元素跟着往下跳一格。大厂把线画在里面（box-shadow: inset 或 outline-offset: -1px），选中变粗时旁边纹丝不动。

② 线要细得像一根头发丝：1px 及以下（Retina 上用 0.5px / hairline）。粗边框是"廉价感"最直接的来源。

/* 线画在里面：选中加粗也不挤动邻居 */
.option{ box-shadow:inset 0 0 0 1px #e6ecf5; }
.option[aria-selected="true"]{ box-shadow:inset 0 0 0 2px #2563eb; }

/* 按钮不画边，用底色 */
.toolbar button{ border:none; background:transparent; }
.toolbar button:hover{ background:#eef3fd; color:#2563eb; }
04 · 圆角必须同心

坑：里外套成一样的数值

外圈 20、里圈也 20（20/20）——看着"统一"，其实拐角处的缝一头宽一头窄（视频里量出来：侧边缝和拐角缝对不上，拐角 11.3）。这就是 AI 生成界面那种"说不上哪里不对"的来源。

正解：外圈 = 里圈 + 缝。20/12 对 8px 的缝，两条弧线严丝合缝、全程平行。

拖动滑块看弧线关系（内圈 = 外圈 − 缝）

内圈12
外圈 = 里圈 + 缝
缝是均匀的：侧边、拐角都是 8px。 
/* 用变量绑定，改一个值内外一起动 */
:root{ --radius-in:12px; --gap:8px; }
.outer{ padding:var(--gap); border-radius:calc(var(--radius-in) + var(--gap)); }
.inner{ border-radius:var(--radius-in); }
自查一句：缝的宽度和拐角弧线的间隙一样吗？不一样就是没同心——把内圈改小到 外圈 − 缝 就好。
05 · 分屏别翻车

坑

拖到 92% 那种尴尬宽度，右边窄成一条缝，鼠标还在死命拽；拖到一半后悔了，找不到回去的路。

大厂在三处兜底：① 分割条是透明玻璃，热区够宽，鼠标划过不卡住 ② 拖过 82% 自动收起，别让人停在 92% ③ Esc 复原、双击对半，随时能回中间。

06 · 彩蛋：长文件名怎么截

坑

2025年度财务报告-最终版-v3.pdf 常见做法是整串尾部省略，变成 2025年度财务报告-最终…——后缀没了，用户看不出这是什么文件。

正解：省略号放在后缀前面，把扩展名保住。

同一个文件名，两种截法（故意压窄，让截断真的发生）
PDF
2025年度财务报告-最终版-v3.pdf
↑ 常见：尾部省略，后缀被吃掉
PDF
2025年度财务报告-最终版-v3.pdf
↑ 大厂：省略号在后缀前面，后缀保住
<!-- 前后分段：前面的可省略，后缀固定不缩 -->
<div class="fname">
  <span class="base">2025年度财务报告-最终版-v3</span>
  <span class="ext">.pdf</span>
</div>

.fname{ display:flex; min-width:0 }
.base{ min-width:0; overflow:hidden; text-overflow:ellipsis; white-space:nowrap }
.ext { flex:0 0 auto }
如果还要更长文件名也不丢信息：把中间那段（版本号、日期）优先省略，头尾都留——但门槛高，日常用"后缀保住"就够了。
