第 5 课 · py-005

if / elif / else 判断

知识要点

1. if = 分岔路
if 让代码「看条件选路」：条件成立（True）走缩进里的代码，不成立就跳过。基本形状： 
t = 37.2
if t >= 38:
    print("发热")      # 只有条件成立才执行
print("分诊结束")      # 无论成不成立都会执行
2. 缩进 = 归属关系（Python 命根子）
缩进的代码属于它上面的 if。缩进错了，程序直接报 IndentationError 崩溃。统一用 4 个空格（PyCharm 按 Tab 自动给 4 空格）。没缩进 = 不属于 if = 无条件执行，这是最常见的隐性 bug。
3. elif = 否则如果；else = 兜底
t = 36.5
if t >= 38:
    print("发热")
elif t >= 37:
    print("正常偏高")
else:
    print("体温正常")    # 前面都不成立才到这里
执行规则（重要）：从上往下依次检查，第一个成立的分支执行完，后面的一律不看。所以顺序不能乱写：必须先问最严格的（发热），再问次严格的（偏高），最后才是兜底。
4. if 后面的条件是什么类型？
条件位置放的是上一课学的比较表达式，结果永远是 bool（True/False）。bool 是分岔路的开关：True 走进去，False 不进去。
一句话总结：if 按条件分路，缩进决定代码归属；elif 是「否则如果」、else 是兜底；从上往下第一个成立的就执行，后面不看。

t = 37.2

同样的代码，t = 36.5 时打印什么？

A. 发热　　B. 正常偏高　　C. 体温正常　　D. 报错

C。36.5 既不满足 >= 38，也不满足 >= 37，最后落到 else 兜底，打印「体温正常」。else 不需要条件：前面全不成立就是它。

下面的代码哪里会报错？

行1: x = 5
行2: if x > 3:
行3: print("大")
行4: print("结束")

A. 行1　　B. 行2　　C. 行3　　D. 行4

C。行3 的 print 没有缩进，但上面是 if 且带了冒号——Python 要求 if 下面必须有缩进的代码块。报 IndentationError: expected an indented block。记住：if 那一行末尾的冒号就是「下面是缩进代码块」的预告。

if 后面的条件，最终要求的类型是？

A. int　　B. str　　C. bool　　D. float

参考答案
C。条件位置放比较表达式（如 t >= 38），结果一定是 bool。True 走进分支，False 跳过。

进阶执行顺序陷阱

执行下面的代码，打印什么？

x = 10
if x > 5:
    print("A")
elif x > 8:
    print("B")
else:
    print("C")

A. A　　B. B　　C. C　　D. A 和 B 都打印

参考答案
A。x > 5 成立，进入 A，整个结构立即结束——哪怕后面的 x > 8 也成立，也不会再看。这是 if/elif 和「逐个检查」最大的区别：elif 只在前面不成立时才轮到。如果想把所有成立的都执行，那是后面学多重 if 的事。

第 6 课 · py-006

for 循环：流水线重复干活

知识要点

1. for = 护士拿名单查房
拿着一张名单，从头到尾逐个处理，每个都执行一遍相同的操作： 
names = ["张", "王", "李"]
for name in names:
    print(name, "请到 3 诊室")
打印三行：每个名字各一行。for 的读法：「名单里每个 name，都做一遍缩进里的事」。
2. 循环变量 = 每次换人的临时盒
name 是循环变量：第一次循环装「张」，第二次装「王」，第三次装「李」。每次进入循环体，它都被换成当前这一轮的值。循环结束后，它停在最后一个值上。
3. range(n) = 造一串数：0 到 n-1，共 n 个
for i in range(3):
    print(i)     # 0 1 2
当日错题：循环次数 = range 里的数的个数。range(3) 有 3 个数（0、1、2），循环就跑 3 次。别被「最后打印的是 2」迷惑——2 是第三个数。
4. range 的变形
range(起点, 终点)：从起点数到终点前一个，range(2, 6) → 2, 3, 4, 5。range(起点, 终点, 步长)：range(0, 10, 2) → 0, 2, 4, 6, 8。规则统一：含起点，不含终点。
一句话总结：for 逐个处理名单或 range 的数；循环变量每轮换新值；range(n) 有 n 个数所以循环 n 次；range 含起点不含终点。

fruits = ["苹果", "香蕉", "橙子"]

进阶累加器

执行下面的代码，最后打印什么？

total = 0
for i in range(1, 5):
    total = total + i
print(total)

A. 4　　B. 10　　C. 15　　D. 报错

参考答案
B。i 依次取 1, 2, 3, 4，total 每次都「吃进」当前的 i：0→1→3→6→10。这个「盒子累加」模式叫累加器，是循环最经典的用法——统计总和、计数都靠它。

用 for + range + 累加器，求 1 到 100 的和，并打印结果。这是高斯小时候做过的题：先想想答案应该比 5000 大还是小，写完跑出来对照一下。

运用药房盘点编号

药品列表 ["阿司匹林", "二甲双胍", "硝苯地平", "奥美拉唑"]。用 for 循环打印带编号的清单：第 1 行「1. 阿司匹林」、第 2 行「2. 二甲双胍」……

提示：用 for i in range(4) 拿到次数 i（0,1,2,3），再通过 drugs[i] 取对应位置的药。编号显示 i+1。

参考答案
drugs = ["阿司匹林", "二甲双胍", "硝苯地平", "奥美拉唑"]
for i in range(4):

解析：range(4) 给出下标 0~3，drugs[i] 按下标取药；编号要显示 1 开头，所以打印 i+1。sep="" 是 print 的「分隔符」参数，设成空字符串就不会在数字和点之间加空格。

第 7 课 · py-007

while 循环 + break / continue

知识要点

1. while = 值班循环（不问次数）
for 是「名单多长就做几遍」；while 是「条件成立就一直做，直到条件不成立」。像个值班护士：只要没到点就继续，到了点就下班。 
x = 0
while x < 3:
    print(x)
    x = x + 1        # 关键：让条件越来越接近不成立
输出 0 1 2。x 从 0 长到 3 时，条件 x < 3 不成立，循环停止。
2. 死循环坑
while 循环体里必须有一条语句让条件越来越接近不成立。如果忘写 x = x + 1，x 永远 < 3，程序永远不结束——死循环，只能强制终止（PyCharm 里点红色停止按钮）。写 while 时先问自己：循环体里哪一行在改变条件？
3. break = 下班（强行结束整个循环）
break 像「今天到此为止」：不管条件还成不成立，直接跳出整个循环。常配合 while True 用：先无条件开始，满足特定条件就 break： 
x = 0
while True:
    print(x)
    x = x + 1
    if x == 3:
        break        # 到 3 就下班
输出 0 1 2。while True 是「永远成立」的条件，全靠 break 来停。
4. continue = 跳过这一个，下一个照做
continue 只跳过当前这一轮剩余的部分，直接进入下一轮。像查房时「这个病人下次再说」，继续查下一个： 
for i in range(4):
    if i == 2:
        continue     # 跳过打印 2
    print(i)
输出 0 1 3。
一句话总结：while 条件成立就一直循环，必须让条件走向不成立；break 整个循环下班，continue 只跳过当前这一轮。

基础停止条件

while 循环什么时候停下来？

A. 循环次数到 10　　B. 条件不成立　　C. 随机时间　　D. 代码行数用完

x = 0

进阶break + continue 组合

执行下面的代码，最后输出什么？

i = 0
while i < 6:
    i = i + 1
    if i == 2:
        continue
    if i == 5:

A. 1 2 3 4　　B. 1 3 4　　C. 1 3 4 5　　D. 1 3 4 5 6

运用题

7
运用猜数字雏形

写一个「猜数字」程序：程序里藏好答案 answer = 7，用 while True 反复让用户 input 猜一个整数（记得 int 转换），猜对了打印「猜对了」并用 break 结束；猜错了打印「不对，再试」。注意：不要给用户无限次机会之外的东西——先跑通再说。

参考答案
answer = 7
while True:
    guess = int(input("猜一个数："))
    if guess == answer:
        print("猜对了")
        break
    else:
        print("不对，再试")
解析：while True 提供「无限机会」，break 在猜对时结束。这是「先无条件循环、满足条件再 break」的标准结构，交互式程序（输入密码、选菜单）都靠它。跑一遍：故意猜错两次再猜对，确认程序行为符合预期。
8
运用登录重试（填空）

密码登录，最多 3 次机会。把下面程序的空填上：

password = "abc123"
times = 0
while times < 3:
    p = input("密码：")
    if p == password:
        print("欢迎")
        ____   # 填 1：登录成功，结束整个循环
    else:
        times = ____   # 填 2：用掉一次机会
        print("密码错误，还剩", 3 - times, "次")
print("程序结束")

两个空分别填什么？填完想：如果 3 次都错，程序会自然退出 while 吗？

参考答案
password = "abc123"
times = 0
while times < 3:
    p = input("密码：")
    if p == password:
        print("欢迎")
        break              # 填 1
    else:
        times = times + 1  # 填 2
        print("密码错误，还剩", 3 - times, "次")
print("程序结束")
解析：填 1 是 break（成功就下班，别继续要密码）；填 2 是 times + 1（每次失败消耗一次机会）。times 从 0 长到 3 时条件不成立，while 自然退出。这个程序同时用到了 while 的条件控制（次数限制）和 break（提前退出），是两者的合体。
第 8 课 · py-008

列表进阶：索引 / 切片 / 增删改

知识要点

1. 索引 = 按编号取货（从 0 开始）
列表里每个位置有编号，叫索引。用 列表[编号] 打开指定柜子：编号从 0 开始（和 range 同一个规矩）。负数编号从右往左数：[-1] 永远是最后一个，不用数长度。 
病人 = ["张三", "李四", "王五", "赵六"]
print(病人[0])    # 张三（第 1 个，编号 0）
print(病人[2])    # 王五（第 3 个，编号 2）
print(病人[-1])   # 赵六（倒数第 1 个）
print(病人[-2])   # 王五（倒数第 2 个）
2. 切片 = 取一段（起点包含、终点不包含）
列表[起点:终点] 从起点开始取，取到终点前一个为止（终点本身不取）。省略起点 = 从头开始；省略终点 = 取到末尾；都省略 = 整份复制。 
病人 = ["张三", "李四", "王五", "赵六"]
print(病人[1:3])   # ['李四', '王五'] —— 1 号到 3 号前
print(病人[:2])    # ['张三', '李四'] —— 开头到 2 号前
print(病人[2:])    # ['王五', '赵六'] —— 2 号到末尾
print(病人[:])     # 整份复制（副本）
医生类比：切片不是复印整个病历，是「复印第 2 页到第 4 页（不含第 5 页）」。
3. 增删改四把钥匙
病人 = ["张三", "李四"]
病人.append("王五")     # 末尾加 → ["张三","李四","王五"]
病人.insert(1, "插队")  # 插到 1 号位 → ["张三","插队","李四","王五"]
病人.remove("插队")     # 按内容删（第一个匹配）→ ["张三","李四","王五"]
del 病人[1]             # 按编号删 → ["张三","王五"]
注意区别：remove 按「内容」找（值），del 按「编号」找（位置）。内容重复时 remove 只删第一个。
一句话总结：索引是「按编号开柜子」（0 起、-1 结尾），切片是「复印一段」（起点算、终点不算），append/insert/remove/del 四把钥匙管增删改。

第 9 课 · py-009

字典进阶：查值 / 改值 / 加项 / 遍历

知识要点

1. 字典 = 带标签的病历卡
列表用「编号」找东西，字典用「名字（键）」找东西。每个 键: 值 成对出现，花括号包裹。像病历卡：字段名是键，填写内容是值。 
患者 = {"姓名": "张三", "体温": 38.5, "诊断": "肺炎"}
print(患者["姓名"])   # 按键取值 → 张三
医生类比：列表 = 按床号找人；字典 = 按住院号/姓名找人。看标签拿东西，不用数位置。
2. 键存在就是改，不存在就是加（核心）
同一个写法 字典[键] = 值，电脑自动判断：键已存在 → 覆盖旧值（改）；键不存在 → 新增一项（加）。 
患者 = {"姓名": "张三"}
患者["体温"] = 38.5      # 键不存在 → 加一项
患者["体温"] = 37.2      # 键已存在 → 改成 37.2
del 患者["体温"]         # 按键删除
3. 遍历字典两种方式
患者 = {"姓名": "张三", "体温": 38.5}
for 键 in 患者:            # 方式1：只拿键
    print(键)              # 姓名 / 体温
for 键, 值 in 患者.items():  # 方式2：键和值一起
    print(键, "=", 值)      # 姓名 = 张三 / 体温 = 38.5
.items() 把每对「键+值」打包递出来，键, 值 两个变量各接一个——像一次拿一双筷子。
一句话总结：字典按「键」干活——取值用 字典[键]，赋值自动分「改/加」，删除用 del；items() 一次递出键值对。

第 10 课 · py-010

阶段综合演练：候诊分诊系统

知识要点

1. 综合运用全景图
本课把 stage-2 所有零件拼成一个小系统：input + float转换 + if/elif/else + while True/break + 列表 + 字典。一个系统 = 数据进来 → 判断 → 存储 → 输出。 
候诊列表 = []                     # 存病人字典的列表
while True:
    姓名 = input("病人姓名（输入 结束 退出）：")
    if 姓名 == "结束":
        break
    体温 = float(input("体温："))  # str → float
    if 体温 >= 38:
        等级 = "急"
    elif 体温 >= 37.2:
        等级 = "普通"
    else:
        等级 = "慢"
    病人 = {"姓名": 姓名, "体温": 体温, "等级": 等级}
    候诊列表.append(病人)
    print(f"已录入：{姓名}（{等级}）\n")
2. 列表套字典 = 档案柜 + 病历卡
这个结构是重点中的重点：外面列表按顺序排（谁先来谁在前），里面字典按标签存（姓名/体温/等级）。存"多条记录"的标准姿势——以后处理文献数据、API 返回的 JSON 全是这个结构。 
病人 = {"姓名": 姓名, "体温": 体温, "等级": 等级}  # 一张病历卡
候诊列表.append(病人)                              # 卡片放进档案柜
3. 按等级叫号 = 三个 for 各筛一级
"急的先看"用三个 for 循环实现：先遍历列表筛出所有"急"，再筛"普通"，最后"慢"——每个 for 都只处理自己负责的等级。 
for 病人 in 候诊列表:
    if 病人["等级"] == "急":
        print("急症优先：", 病人["姓名"], 病人["体温"], "度")
for 病人 in 候诊列表:
    if 病人["等级"] == "普通":
        print("普通门诊：", 病人["姓名"], 病人["体温"], "度")
一句话总结：候诊分诊系统 = 录入（while+input）→ 分诊（if/elif/else）→ 存储（列表套字典）→ 叫号（for 按等级筛）——一个真实小系统的完整闭环。
