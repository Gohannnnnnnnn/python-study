第 23 课 · py-023

读写文件：把数据存进硬盘

知识要点

1. open 三种模式——r / w / a
f = open("记录.txt", "r")   # r=读，文件必须存在
f = open("记录.txt", "w")   # w=覆盖写，原有内容全没
f = open("记录.txt", "a")   # a=追加写，保留原有，从末尾加
医生类比：r = 翻病历看；w = 撕掉重写一页；a = 翻开最后一页继续记。a 是「打开模式」不是方法——append 是列表的方法，别混。
2. 读文件三步 + 逐行读
f = open("记录.txt", "r", encoding="utf-8")
内容 = f.read()          # 一次性全读进来
f.close()

# 大文件逐行读（省内存）：
f = open("记录.txt", "r", encoding="utf-8")
for 行 in f:            # 一行一行取
    print(行.strip())
f.close()
3. ⚠️ encoding 必须写 + 不 close 的后果

中文文件必须写 encoding="utf-8"，否则 Windows 默认按 gbk 读 → 乱码。

不 close() → ① 数据还在缓冲区没落盘；② 文件被占用别人打不开。

一句话总结：r 读、w 覆盖、a 追加；读文件 open → read/for 行 → close；中文必须 encoding="utf-8"；忘 close 数据不落盘还占着文件。

练习题

1
基础打开模式

想在文件末尾接着写、不清空原有内容，用哪个模式？

A. r　　B. w　　C. a　　D. rw

参考答案
C。a = 追加（append），保留原有内容从末尾加；w 会覆盖清空。
2
基础编码

读一个含中文的 txt 文件，打开时漏写 encoding="utf-8"，会发生什么？

A. 正常　　B. 中文乱码　　C. 直接报错　　D. 文件打不开

参考答案
B。Windows 默认 gbk 解码，utf-8 文件的中文会变成乱码。
3
基础close

写文件后不调用 close()，下面哪个后果是真的？

A. 数据立刻丢失　　B. 数据可能没落盘 + 文件被占用　　C. 程序报错　　D. 没有任何影响

参考答案
B。不 close，数据停在缓冲区没真正写进硬盘，文件还被占用着。
4
进阶逐行读

读一个 10 万行的日志文件，下面哪种方式最省内存？

A. f.read() 一次性全读　　B. for 行 in f 逐行读　　C. 都差不多　　D. 都没法读大文件

参考答案
B。read() 会把 10 万行全塞进内存；for 行 in f 一次只读一行。
5
进阶模式语义

open("x.txt", "w") 再写一句话，会怎样？

A. 追加到末尾　　B. 覆盖掉原文件内容　　C. 报错（文件已存在）　　D. 什么也不写

参考答案
B。w = 覆盖写，先清空再写，原有内容全没。
第 24 课 · py-024

with 语句 + JSON 读写

知识要点

1. with 语句——自动关门
# 以前：手动关，忘写 f.close() 就出事
f = open("记录.txt", "a", encoding="utf-8")
f.write("张三 36.8\n")
f.close()

# 现在：with 自动关
with open("记录.txt", "a", encoding="utf-8") as f:
    f.write("张三 36.8\n")
# 缩进一结束，Python 自动 close
医生类比：with = 进病房门设成「自动关」，缩进里做事，离开自动锁门——再也不用记 f.close()。
2. json.dump 存 / json.load 读——类型不变
import json

病人 = {"姓名": "王五", "体温": 39.0}
with open("病人.json", "w", encoding="utf-8") as f:
    json.dump(病人, f, ensure_ascii=False)   # 存

with open("病人.json", "r", encoding="utf-8") as f:
    读回 = json.load(f)                        # 读
print(读回["体温"])   # 39.0
方向别记反：dump = 倒进去存，load = 装出来读。存的是字典，读回来还是字典（类型不变）。
3. ⚠️ 存多个记录用「列表套字典」
# 一个字典装不下两个病人（一个键一个值）——外层要用列表
病人 = [
    {"姓名": "王五", "体温": 39.0},
    {"姓名": "赵大", "体温": 38.8}
]
with open("病人.json", "w", encoding="utf-8") as f:
    json.dump(病人, f, ensure_ascii=False)

# 读回来是列表，取值要剥两层：
读回 = json.load(open("病人.json", "r", encoding="utf-8"))
print(读回[0]["姓名"])   # 王五（先 [0] 取第几个，再 ["姓名"] 取字段）
ensure_ascii=False：中文原样存，不转成 \u 乱码。
一句话总结：with 自动关门省心；json.dump 存、json.load 读、类型不变；存多个记录用列表套字典；方法调用永远用 () 不是 {}。

练习题

1
基础with

with 语句最大的好处是什么？

A. 读写更快　　B. 自动关闭文件，不用写 close()　　C. 能读大文件　　D. 不用写 encoding

参考答案
B。with 缩进结束后自动 close，防忘关文件。
2
基础dump/load

把字典存进 json 文件用哪个？从文件读回用哪个？

A. 存 json.load / 读 json.dump　　B. 存 json.dump / 读 json.load　　C. 都 json.dump　　D. 都 json.load

参考答案
B。dump = 倒进去存，load = 装出来读。
3
基础类型

把「列表套字典」用 json.dump 存进文件，json.load 读回来是什么类型？

A. 字符串　　B. 字典　　C. 列表（元素是字典）　　D. 报错

参考答案
C。存什么读回什么——存列表套字典，读回还是列表套字典。
4
进阶嵌套取值

读回 = [{"姓名":"王五"},{"姓名":"赵大"}]，取「赵大」怎么写？

A. 读回[1]["姓名"]　　B. 读回["姓名"][1]　　C. 读回[0]["姓名"]　　D. 读回[2]

参考答案
A。先 [1] 取第二个字典，再 ["姓名"] 取字段。索引从 0 起，赵大是第 1 个。
5
进阶报错排查

病人 = {"姓名":"王五"}; 病人.append({"姓名":"赵大"}) 会怎样？

A. 正常，病人变两个　　B. 报错：dict 没有 append　　C. 报错：语法错　　D. 病人变列表

参考答案
B。病人是字典，append 是列表专属方法，字典没有。存多个要用列表套字典。
