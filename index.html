复现 4 次

主题：局部变量：函数里创建的变量，外面看不见

def f(): score = 100; return score，f() 之后外面 print(score) 报 NameError。return 递的是「值」，不是「名字」——外面必须 结果 = f() 接住才有。

一句话心智模型：函数 = 独立房间，门一关里面的东西就消失；要靠 return 递出来，并且在外面接住。
复现 4 次

主题：集合：能改但不能按号取，加元素用 add

把 append 套到集合上（s.append(4)）→ AttributeError。append 是列表专属，集合加元素用 add；集合无序，不能用 s[0]。

一句话心智模型：列表用 append（有位置），集合用 add（没位置）；能按编号取的是列表和元组。
复现 4 次

主题：统计「每个 X 的次数」= 字典模式

选「列表 + count()」——能跑但慢，每数一个词就扫一遍全表。正解：X 做键、次数做值，遍历时累加。

一句话心智模型：统计次数一律用字典：X 为键、次数为值；一遍过，不回头扫第二遍。
复现 3 次

主题：字典重复键 = 覆盖

以为字典保留第一次的值，实际后写覆盖先写。每个键永远只有一个值。想留多个值就把它当列表用。

一句话心智模型：统计次数用字典，重复键会覆盖——「每个键一个值」是字典的铁律。
复现 3 次

主题：函数里写全局变量要先 global

函数内 x = x + 1 → UnboundLocalError。Python 见赋值即认定该名字是局部的，右边那个 x 反而没定义。

一句话心智模型：函数里「读」全局随便读，「写」必须先 global——不声明就报错。
2026-09-13 新

主题：循环里赋值 = 覆盖，攒不住东西

total = float(row["amount"]) 写在循环里，每轮都把上轮的值扔掉，循环结束只剩最后一个。累加变量必须在进循环之前就存在。

一句话心智模型：循环里的赋值不是新增，是换掉；想攒东西只能「自己 = 自己 + 新值」。
2026-09-13 新

主题：方法调用用 ()，不是 {}

病人.append{...} → SyntaxError。[] 取索引、{} 造容器，只有 () 能「调用」。

一句话心智模型：调用永远是 名字(...)——圆括号才是动作，方括号花括号都是装东西的。
2026-09-13 新

主题：CSV / 文件读出来的一切都是字符串

写进去是数字 18，DictReader 读回来是 '18'，直接算数就错。要先 float() 转。

一句话心智模型：从文件 / 键盘进来的东西，Python 一律当文本（跟 input() 一个毛病）。
