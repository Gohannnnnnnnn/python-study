① 四容器一眼看全
容器符号有顺序？能改？怎么取值去重？一句话
列表[]✅✅[编号]❌值班表
元组()✅❌[编号]❌出生日期
字典{"k":v}✅✅["键"]键去重病历卡
集合{}❌✅❌ 不能[0]✅住院号登记本
核心口诀：列表能改有顺序 / 元组只读有顺序 / 字典按键找值 / 集合自动去重。
集合最特殊：无序 → 不能 s[0]！
② 选容器决策树（拿到数据先问 4 个问题）
拿到数据，先问自己： ┌─ 要按顺序存吗？────────┐ │ 是 → 要改吗？ │ │ 是 → 列表 [] │ │ 否 → 元组 () │ │ 否 → 要按键找吗？ │ │ 是 → 字典 {键:值} │ │ 否 → 要自动去重吗？ │ │ 是 → 集合 {} │
医生场景对照：值班表=列表 / 出生日期=元组 / 病历卡=字典 / 住院号登记=集合。
③ 嵌套结构：剥洋葱三步
病人列表 = [ {"姓名":"张三",...}, {"姓名":"李四",...} ] ↓ ① 最外层是 [（列表） [0] → {"姓名":"张三",...}（字典） ② 剥一层：[编号] ["姓名"] → "张三"（字符串） ③ 再剥：["键"] → 到头

取值 = 列表[编号]["键"]——先抽卡，再看字段。多层就多剥几次。

结构长什么样取值例子
列表套列表[[1,2],[3,4]]x[1][0] = 3
列表套字典 ⭐[{"a":1},{"a":2}]d[1]["a"] = 2
字典套字典{"x":{"y":99}}e["x"]["y"] = 99
API 返回的 JSON 全是这种结构——学会剥洋葱 = 学会读 JSON。以后调 DeepSeek API 天天用。
