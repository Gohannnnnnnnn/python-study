弹窗家族 · 全家福

16 种浮层，按家族分类 · 说准名字，AI 才写得对
先记一条主线：所有浮层按"打不打断用户"分三类——
非模态（不打断，用户该干嘛干嘛）→ 轻提示类
半模态（占一块，但背后还在）→ 面板类
模态（挡住，必须处理）→ 对话类
整理自 Ludi 的抖音两期视频（2026-10-19 / 10-28）
一、对话类 · 模态（会挡住，必须处理）
Modal模态弹窗
居中弹出 + 遮罩，整页锁住，处理完才能继续。
话术：「点新增用 Modal 弹一个表单」
AlertDialog警报阻断弹窗
比普通 Modal 更"重"的确认框：专门用于不可逆、有后果的操作（删除全部、退出不保存）。按 Esc 可关。
话术：「删除前用 AlertDialog 拦一下，写清后果」
普通提示别用它——太重。
Popconfirm气泡确认
就在按钮旁边弹个小气泡问"确定吗"，鼠标不用挪窝。
话术：「删除按钮加 Popconfirm 二次确认」
二、面板类 · 半模态（装内容，背后还在）
Drawer抽屉
从侧边滑出。背后列表还在，焦点不丢——适合"边看边改"。
话术：「点这行，用 Drawer 从右边滑出编辑面板」
Bottom Sheet底部半屏面板
从底部升起，占半屏。抖音评论区就是这个——所以它不是抽屉（抽屉在侧边）。
话术：「评论列表用 Bottom Sheet，从底部升起」
移动端最常用的一种，替代"新建一个页面"。
ActionSheet底部动作面板
底部弹出的一列大按钮，每个是一个动作（更换头像 / 个性签名 / 设置）。
话术：「点头像从底部弹 ActionSheet，列出操作」
Popover气泡卡片
点一下弹出的小浮层，可以放按钮、链接（比 Tooltip 重，能交互）。
话术：「点头像弹 Popover 菜单」
三、轻提示类 · 非模态（不打断）
Toast轻提示
一闪而过（2-3 秒自动消失），不挡操作。
话术：「保存成功后弹个 Toast」
Snackbar底部撤销条
屏幕底部浮一条黑条，带一个操作按钮（"已删除 1 封邮件 · 撤销"）。
话术：「删除后底部弹 Snackbar 带撤销按钮」
和 Toast 的区别：Toast 只能看，Snackbar 能点。
Inline Alert行内校验
错误就地显示在输入框下方（"请输入 11 位手机号"），不是飘走。
话术：「手机号格式错误用 Inline Alert 显示在输入框下」
表单校验千万别用 Toast——几秒就消失，用户回头看不到错在哪。
Alert警告条
嵌在页面里的横幅，常驻到条件消失。
话术：「页面顶部放个 Alert 提示截止时间」
Notification通知
从角落滑入，停留几秒，可堆叠多条。
话术：「导出完成后右上角发 Notification」
Tooltip文字提示
悬停（手机上长按）出现的一小段文字，只解释不能点。
话术：「这个问号图标加个 Tooltip」
四、另外三张"熟脸"（容易忽略但常用）
Loading加载态
转圈 / 骨架屏，告诉用户"在等"。超过 1 秒不反馈，用户就会以为卡死。
话术：「请求时显示 Loading，别让页面静着」
Tour新手引导
一步步高亮界面元素 + 说明气泡（"新功能上线：给背景打个聚光灯"）。
话术：「新功能首次进入做一个 Tour 引导」
Lightbox灯箱
点图片后全屏放大查看，背景变暗。
话术：「点图片用 Lightbox 全屏查看」
五、选型：用哪个？（按情况查表）
你想干什么用哪个
提示一下就走Toast
提示 + 可撤销Snackbar
表单填错Inline Alert
解释一个图标Tooltip
删除前问一句Popconfirm
不可逆操作，必须拦住AlertDialog
中等表单，专心填完Modal
边看列表边改详情Drawer
移动端看评论 / 详情Bottom Sheet
底部列出一堆操作ActionSheet
内容极多新页面
判断法① 看内容长短：1440px 屏下表单一超长 → 出局，改 Drawer 或新页面。
判断法② 要不要左右对照：要 → Drawer（背后列表还在，焦点不丢）；不要 → Modal。
六、打扰指数（越低越好）
Toast25 最低
Alert45
Popconfirm60
Drawer
Modal最高
原则：能用轻的就别用重的。用户每被打断一次，就多一次想关掉你的冲动。
七、3 个坑（90% 的人都踩过）
坑 ①
填表的弹窗，别"点蒙层就关"
用户填一半手滑点到旁边 → 数据全没。要么禁止点蒙层关闭，要么加草稿自动保存。
坑 ②
能撤销，就别二次确认
删了能找回（有回收站）→ 直接删 + Snackbar 撤销条；删了找不回 → 才用 AlertDialog / Popconfirm 拦一下。
坑 ③
按钮别写"是 / 否"
用户在弹窗上的注意力只有 0.2-0.3 秒（299ms）。按钮直接写动作——"确认退票"而不是"是"，后果写在旁边（"将扣除 30 元"）。
