函数公式卡定义 / 参数 / 返回值 / 作用域 / lambda · 写代码时对着查

① 核心公式：定义 + 调用
定义（写菜谱）
def 函数名(参数):
    return 结果          # 干活，然后把结果交出去
调用（照菜谱做菜）
结果 = 函数名(实参)     # 喂进去，接住 return 交出来的值
口诀：def 是「写菜谱」，函数名(实参) 是「照菜谱做菜」。定义了不调用 = 菜谱写完没下锅 = 白写。
② return vs print（最容易混）
return 值print(值)
作用把值交出去只是显示
结果能拿到吗✅ 结果 = 函数()❌ 拿不到
类比递到你手里喊一嗓子
一句话：print 喊一嗓子，return 递给你。想继续用结果，必须 return。
③ 参数三件套 + 三条铁律
类型写法规则
位置参数f(1, 2)按顺序对号入座
默认参数def f(a, b=2)不填就用默认
关键字参数f(a=1, b=2)点名传，顺序随便
三条铁律（反复考）：
① 定义时：默认参数在后 —— def f(a, b=1) ✅ / def f(a=1, b) ❌
② 调用时：位置参数在前 —— f(1, b=2) ✅ / f(b=2, 1) ❌
③ 传参时：显式传参覆盖默认 —— f(1, c=10) 里 c=10，不是默认值
一句话：默认值是兜底——你填了用你的，没填用我的。
④ 返回值：多值 + 无 return
多值 return → 多个盒子接（拆包）
def 评估(体温, 心率):
    return 体温, 心率        # 一次吐两个值

体, 心 = 评估(38.5, 110)     # 两个盒子接住
不写 return → 函数返回 None（啥也没有）。要用结果就必须 return。
⑤ 作用域（错题重灾区，三连口诀）
情况能不能写法
读全局✅ 随便读return 总数 + x
直接写全局❌ 报错总数 = 总数 + x → UnboundLocalError
声明后写✅global 总数; 总数 += x
口诀：读可以、写要 global、声明+写成功。
根源：Python 先扫函数体，见赋值即认定该变量是局部，等号右边读的永远是未定义的局部。
局部变量：函数里创建的变量，函数结束就消失——外面看不见，必须 return 递出来。外面再写同名变量 = 新开一个盒子，跟函数里那个无关。
⑥ lambda：一行版函数
公式
lambda 参数: 表达式      # 自动 return，不用写 def / return

# 等价于
def f(参数):
    return 表达式
最常见用法：当排序的「临时规则」 sorted(病人列表, key=lambda p: p["体温"]) # 按体温排 sorted(病人列表, key=lambda p: p["体温"], reverse=True) # 高→低
⑦ 内置函数速查
函数作用例子
len(x)数个数len([1,2,3]) → 3
sum(列表)求和sum([1,2,3]) → 6
max / min最大 / 最小max([1,2,3]) → 3
sorted(列表, key=..., reverse=...)按规则排序key 定规则，reverse=True 倒序
