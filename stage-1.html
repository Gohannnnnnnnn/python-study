第 1 课 · py-001

print / 变量 / 顺序执行

知识要点

1. 代码 = 给计算机的菜谱
程序不是魔法，是一行一行写好的指令。计算机像厨师一样从上到下、逐行执行，每行都做一件明确的小事。哪一行出错，程序就在哪一行停下来。
2. 引号 = "这是文本"的标记
print("1+2") 输出 1+2（原样念出来，不计算）；print(1+2) 先算出 3，再输出 3。引号告诉 Python：「里面的东西别当代码，当作文字处理」。 
print("1+2")   # 输出：1+2   （引号内是文字，原样念）
print(1+2)     # 输出：3     （没有引号，先计算）
3. 变量 = 贴标签的盒子
x = 3 意思是：造一个盒子，贴上标签 x，把 3 装进去。= 的读法是「把右边的装进左边」。盒子可以换内容：再执行 x = 20，x 里就变成 20（旧东西被换掉）。
4. 赋值是复制，不是改名
b = a 是把 a 盒子里的东西复制一份装进 b。之后 a 换新东西，b 还是原来那份，互不影响。 
a = 1
b = a      # 复制：b 里也装 1
a = 10     # a 换新内容
print(a)   # 10
print(b)   # 1   ← b 不受影响
一句话总结：代码从上到下逐行执行；引号让内容变文字；变量是贴标签的盒子；= 是把右边装进左边，b = a 是复制不是绑定。

A. 5　　B. 2+3　　C. 报错　　D. "2+3"（连引号一起显示）

基础变量赋值

哪一行是「把 3 装进盒子 x」的正确写法？

A. x = 3　　B. 3 = x　　C. x == 3　　D. print(x)

参考答案
A。等号左边必须是盒子的名字（变量名），右边是装进去的内容。B 把 3 当盒子，语法错误；C 的 == 是「问是否相等」，不是赋值；D 只是打印 x 里的内容。
3
基础顺序执行

下面代码的输出顺序是什么？

print("A")
print("B")

A. B 然后 A　　B. A 然后 B　　C. 随机顺序　　D. 报错

参考答案
B。Python 从上到下逐行执行，先执行第一行 print("A")，再执行第二行，所以先 A 后 B。

进阶题

4
进阶变量换内容

执行下面的代码，输出什么？

x = 10
print(x)
x = 20
print(x)

A. 10 然后 20　　B. 20 然后 20　　C. 10 然后 10　　D. 报错

参考答案
A。盒子 x 先装 10，第一次 print 输出 10；然后 x 换装 20，第二次 print 输出 20。print 打印的是「执行到那一行时盒子里装的东西」，不是盒子的历史。

进阶赋值=复制

这是当日错题原题：执行后 print(b) 输出什么？

a = 1
b = a
a = 10
print(b)

A. 1　　B. 10　　C. 报错　　D. 11

参考答案
A。b = a 时 a 里装的是 1，于是复制一份 1 给 b。之后 a 换成 10，b 手里还是当初复制的那份 1。类比：病历复印件已经印出来了，原件改了，复印件不变。

运用交换两个变量

已知 x = 3，y = 8。要求：只写 3 行代码（允许用一个临时变量 temp），让交换后 x = 8、y = 3。

提示：先想「直接写 x = y 行不行？」——不行，那 y 的原值 3 就被覆盖丢了。需要先把一个值存到安全的地方。

参考答案
temp = x   # 先把 x 里的 3 存进 temp 保命

y = temp   # y 拿到当初的 3
解析：这和「两手各拿一个杯子要交换液体，必须先借第三个空杯」是同一个道理。temp 就是那个借来的空杯。这是编程里的经典操作，后面学函数、排序都会用到。

运用预测输出

不运行代码，在纸上写出下面程序的完整输出，并给每一行写一句注释说明「此刻每个盒子里装的是什么」：

a = 1
b = a
a = 10
print(a)
print(b)
参考答案
# 盒子 a 装 1
# 复制：盒子 b 也装 1
# 盒子 a 换装 10
print(a)   # 输出 10

第 2 课 · py-002

数据类型：int / float / str / bool

知识要点

1. 类型 = 标本的标签
数据分类型，就像化验标本分血常规、尿常规。Python 常见四种：
类型中文名例子说明
int整数3 -2 0没有小数点的数
float浮点数（小数）3.0 36.5带小数点的数，体温、化验值都是它
str字符串（文本）"发热" "38.5"必须带引号，内容可以是任何文字
bool布尔值True False只有两个值：真 / 假
2. 同一个 + 号，行为由类型决定
「类型决定行为」是本课核心：同样是 +，遇到不同类型干不同的活。 
print(3 + 4)      # 7   数字相加
print("3" + "4")  # 34  文本拼接（把两段文字接在一起）
print(3 + 4.0)    # 7.0 整数+小数 → 自动升级成小数，防丢精度
3. 类型不匹配会报错
"3" + 4 会报 TypeError：文本和数字是两种标本，不能直接混着加。必须先转换（下一课讲）。另外注意：10 / 2 结果是 5.0（float）——除法永远返回小数，即使能整除。
一句话总结：每个值都有类型；+ 遇到数字相加、遇到文本拼接、遇到 int+float 自动升级；类型混用会报 TypeError。

练习题

基础题

1
基础文本拼接

print("3" + "3") 输出什么？

A. 6　　B. 33　　C. 报错　　D. 3+3

参考答案
B。两边都是带引号的文本（str），+ 是拼接，把 "3" 和 "3" 接在一起成 "33"。注意它不是数字 33，而是两个字符组成的文本。

基础识别类型

下面哪个值是 float 类型？

A. 7　　B. 7.0　　C. "7"　　D. True

参考答案
B。7 是 int，7.0 带小数点所以是 float，"7" 带引号是 str，True 是 bool。
3
基础除法类型

print(10 / 2) 的结果是什么类型？

A. int　　B. float　　C. str　　D. 报错

参考答案
B。除法（/）永远返回 float，即使 10 / 2 能整除，结果也是 5.0 而不是 5。这是 Python 的规定：除法可能产生小数，干脆一律给小数。

进阶题

进阶自动升级

3 + 3.0 的结果是？

A. 6　　B. 6.0　　C. "33"　　D. 报错

参考答案
B。int + float 时，Python 自动把 int 升级成 float 再相加，结果是 6.0。规则：整数和小数相遇，结果保小数，绝不丢精度。
5
进阶TypeError

哪一行会报错？

行1: print(3 + 4)
行2: print("3" + 4)
行3: print(3.0 + 4)

A. 行1　　B. 行2　　C. 行3　　D. 都不报错

参考答案
B。行2 是 str + int：文本和数字不能直接相加，报 TypeError。行3 是 float + int，自动升级没问题。记住报错信息长这样：TypeError: can only concatenate str (not "int") to str——翻译过来就是「文本只能和文本拼接，不能和整数拼」。

运用题

6
运用体温上升计算

患者基础体温 36.5（float），现在上升 0.3 度。写两行代码：第一行用变量 t 存基础体温，第二行计算并打印新体温。再想一想：如果体温是文本 "36.5"，直接 "36.5" + 0.3 会怎样？

参考答案
t = 36.5
print(t + 0.3)   # 输出 36.8，float + float 正常相加
延伸："36.5" + 0.3 会报 TypeError——文本和数据是两种标本。如果数据是从 input() 或文件里来的，常常是文本，需要先转换（下一课专门讲）。
7
运用报告单打印

白细胞数值 6.8，单位是 x10^9/L。用变量存数值和单位，用一行 print 打印出完整的报告行：WBC: 6.8 x10^9/L。

提示：数值是 float、文字是 str，不能直接相加。但 print 可以一次接收多个内容，用逗号隔开，它们会被空格连起来。

参考答案
wbc = 6.8
unit = "x10^9/L"
print("WBC:", wbc, unit)   # WBC: 6.8 x10^9/L
解析：print 用逗号隔开多个值，会把它们按顺序打印并用空格连接，自动把数字转成文字显示。这是「数字和文本要一起显示」时最省事的办法。
第 3 课 · py-003

input 输入与类型转换

知识要点

1. input() = 停下来问病人主诉
程序跑到这里会停住，等你在屏幕上输入内容、按回车，才继续往下走。input 括号里可以写提示语： 
name = input("请输入姓名：")
print("你好", name)
2. 核心坑：input 返回永远是 str
不管用户输入 38.5 还是 3，input 拿到手的都是文本。所以 input("体温：") + 0.5 必然 TypeError——必须先转换。
3. 类型转换 = 换标本管
float(x) 把内容转成小数、int(x) 转成整数、str(x) 转成文本。转换规则不一样，注意区分：
写法结果原理
int(3.5)3物理截断：直接把小数部分倒掉，不报错
int("3.5")报错 ValueError读文本：内容必须长得像整数（如 "3"），带小数点就拒收
float("38.5")38.5文本内容长得像小数，成功转换
float("体温")报错 ValueError文本内容不是数字，转换失败
4. 嵌套写法：从里往外执行
t = float(input("体温："))——先执行最里面的 input() 拿到文本，再交给 float() 转成小数，最后装进盒子 t。一层套一层，像剥洋葱，从里往外。
一句话总结：input 拿到的一律是文本；要算数必须先转换；float→int 是倒掉小数，str→int 是读文本（内容必须整数写法，否则报错）。

练习题

基础题

基础input 返回值

用户输入 38.5 并回车，input() 返回的值是什么类型？

A. float　　B. str　　C. int　　D. 看运气

参考答案
B。input 永远返回 str，哪怕内容是数字。这是新手最常踩的坑：输入 38.5 拿到的是文本 "38.5"，直接做算术会报错。

基础选择转换函数

要把文本 "38.5" 变成能做运算的小数，用哪个？

基础哪行报错

哪一行会报错？

行2: y = float("5")

A. 行1　　B. 行2　　C. 行3　　D. 都不报错

参考答案
C。int 读文本要求内容是「整数写法」，"5.9" 带小数点，拒收 → ValueError。行1 的 "5" 是整数写法，没问题；行2 float 接受 "5"（转成 5.0）。

运用BMI 计算器雏形

用 input 询问身高（米）和体重（kg），把两个输入都转成 float，计算 BMI = 体重 ÷ 身高² ，打印结果。写完在 PyCharm 里跑一遍，输入 1.75 和 70，看输出是不是约 22.86。

运用年龄 +1

用 input 问「今年几岁」，用户输入 35。程序打印「明年你就 36 岁了」。写代码，并解释：为什么必须用 int() 转换？如果不转换直接 "35" + 1 会发生什么？

参考答案
age = int(input("今年几岁："))
print("明年你就", age + 1, "岁了")
解析：必须 int() 是因为 input 拿到的是文本 "35"，"35" + 1 是 str + int，报 TypeError（文本只能拼文本）。转成 int 后 35 + 1 = 36，是正常加法。如果直接 "35" + "1"，得到的是 "351"——拼接不是加法，这是文本和数字的本质区别。
第 4 课 · py-004

布尔值与比较运算

知识要点

1. bool = 化验单的阳/阴
布尔值只有两个：True（真）和 False（假）。它是一切判断的「原料」——下一阶段 if 就是靠它决定走哪条路。
2. 6 个比较符号，结果永远是 bool
符号含义例子结果
==等于（问相等）3 == 3True
!=不等于3 != 4True
> / <大于 / 小于5 > 3True
>= / <=大于等于 / 小于等于5 >= 5True
区分 == 和 =：== 是「问一问两者相等吗」（输出 True/False）；= 是「把右边装进左边」（赋值）。一个问问题，一个放东西。
3. 比较前提：类型匹配
float("38.5") > 37 → True（都是数字，能比）；但 "38.5" > 37 → 报 TypeError。文本和数字没法「比个子」，必须先转换。这里有个例外要记住："3" == 3 不报错，返回 False（== 是验明正身，类型不同直接说不认识）。
4. 区间写法
体温 37 到 37.5 之间（含两端）：37 <= t <= 37.5。Python 支持这种「连写」的比较，读起来和数学一模一样。注意它包含边界：t 恰好等于 37 或 37.5 都算 True。
一句话总结：比较符号产出的永远是 True/False；== 验明正身（类型不同→False），> 比个子（类型不同→报错）；数字和文本必须先转换再比。

练习题

基础题

1
基础哪个是 True

下面哪个表达式结果是 True？

A. 1 == 2　　B. 3 == 3　　C. "3" == 3　　D. 3 > 5

参考答案
B。3 == 3 相等，True。C 是文本和数字比相等：不报错，但类型不同直接返回 False。A、D 明显不成立。
2
基础转换后比较

float("38.5") > 37 的结果是？

A. True　　B. False　　C. 报错　　D. 38.5

参考答案
A。先转换：float("38.5") 变成数字 38.5，再和 37 比，38.5 > 37 成立 → True。先换标本管，再比个子。
3
基础类型不匹配

"38.5" > 37 的结果是？

A. True　　B. False　　C. 报错　　D. 无法确定

参考答案
C。文本和数字「比个子」没有意义，Python 直接报 TypeError：'>' not supported between instances of 'str' and 'int'。这和 == 不同——== 是问「是不是同一个」，类型不同也能答「不是」；> 必须同类才能比。

进阶题

4
进阶区间与边界

表达式 37 <= t <= 37.5 在 t = 37.5 时结果是？在 t = 37.6 时呢？

A. True / True　　B. True / False　　C. False / False　　D. False / True

参考答案
B。区间写法包含两端：t = 37.5 正好压线，True；t = 37.6 超出上限，False。判断体温是否「正常偏高」这类边界问题，先想清楚含不含等号。
5
进阶== 与 = 的区别

执行下面两行，分别会发生什么？

print(5 == 5)
print(5 = 5)

A. True / True　　B. True / 报错　　C. 报错 / True　　D. 都报错

参考答案
B。第一行 == 是问「5 等于 5 吗」，输出 True。第二行 = 是赋值，要求左边是盒子的名字，而 5 不是名字 → 语法错误。看到 SyntaxError: cannot assign to literal 就要想到：是不是把 == 写成 = 了。

运用题

6
运用发热初筛

用 input 让用户输入体温，转 float。写代码判断并打印三行结论：是否 >= 38（发热）、是否 < 36（体温偏低）、是否在 36 到 37.5 之间（正常范围，含两端）。每个判断一行，输出 True/False。

参考答案
t = float(input("体温："))
print("发热：", t >= 38)
print("偏低：", t < 36)
print("正常：", 36 <= t <= 37.5)
解析：三个判断互不冲突，可以都打印。这就是「先产生布尔值，再拿布尔值说话」的思路——下一课 if 会把 True/False 变成真正的分岔路。
7
运用血型核对

写代码：用两个变量存患者登记血型 reg = "A" 和复查血型 retest = "A"，用 == 判断是否一致并打印 True/False。然后把 retest 改成 "B" 再跑一次，观察输出变化。最后想一想：如果用 > 比 "A" 和 "B"，会报错吗？为什么？

参考答案
reg = "A"
retest = "A"
print("血型一致：", reg == retest)   # True

retest = "B"
print("血型一致：", reg == retest)   # False
延伸："A" > "B" 不报错——因为两个都是文本，文本之间可以比（按字母顺序，A 在 B 前所以 False）。但文本和数字不能比。规则总结：同类型能比，== 例外（不同类型也能答「不是」）。
