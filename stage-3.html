第 11 课 · py-011

元组与集合：容器家族新成员

知识要点

1. 元组 = 只读列表（() 创建）
元组和列表几乎一样（有顺序、能索引、能切片），唯一区别：创建后不能改——不能增、不能删、不能改值。 
坐标 = (3, 5)          # 圆括号 () 创建
病人 = ("张三", "男", "2026-08-01")
print(坐标[0])          # 3 —— 能查（索引和列表一样）
坐标[0] = 9             # ❌ 报错！元组不能修改
医生类比：列表是「值班表」（随时加人删人），元组是「病历上的出生日期」（录进去就不能改——固定记录）。
2. 集合 = 去重口袋（{} 无冒号）
集合三大特性：自动去重（重复只留一个）、无序（没有编号）、能增删（add / remove）。 
体温记录 = {37.2, 38.5, 37.2, 36.8}   # 花括号 {} 但里面没有冒号
print(体温记录)   # {36.8, 37.2, 38.5} —— 37.2 只出现一次！

名单 = {"张三", "李四"}
名单.add("王五")        # 加一个
名单.add("张三")        # 已有 → 不重复加
名单.remove("李四")     # 删一个
医生类比：集合是「住院号登记本」——同一个病人挂几次号，登记本上只有一个号。
3. 容器家族全家福
容器符号顺序能改按键找去重
列表 list[]✅✅编号❌
元组 tuple()✅❌编号❌
字典 dict{} 键:值✅✅键键去重
集合 set{} 无冒号❌✅❌✅
记忆口诀：列表能改有顺序，元组只读有顺序，字典按键找值，集合自动去重。
4. 实战：统计不同种类
体温列表 = [37.2, 38.5, 37.2, 36.8, 38.5]
种类数 = len(set(体温列表))     # 列表转集合 → 去重 → 数个数
print("不同体温种类：", 种类数, "种")   # 3 种
set(列表) 把列表变成集合自动去重，len() 数个数——这是统计"有几种"的标准姿势。
一句话总结：元组是只读列表（防误改），集合是去重口袋（无序、无编号）——"能按编号取"的前提是有顺序，集合为了去重牺牲了顺序。

练习题

基础题

1
基础元组只读

元组 t = (1, 2, 3)，执行 t[0] = 99 会怎样？

A. t 变成 (99, 2, 3)　　B. 报错（元组不能改）　　C. 变成 [99, 2, 3]　　D. 静默忽略

参考答案
B。元组创建后不能修改——增删改都不行。想改就换列表。
2
基础集合去重

s = {1, 2, 2, 3, 3, 3}，print(s) 输出？

A. {1, 2, 2, 3, 3, 3}　　B. {1, 2, 3}　　C. (1, 2, 3)　　D. 报错

参考答案
B。集合自动去重：重复元素只保留一个，输出 {1, 2, 3}（顺序可能不同，因为无序）。
3
基础集合索引

集合能像列表一样用 s[0] 取第一个元素吗？

A. 能，从 0 开始　　B. 不能，集合无序没有编号　　C. 能，但只能取一次　　D. 报错

参考答案
B。集合无序，没有"第 0 个"的概念。s[0] 会报 TypeError。集合只能整体用（for 遍历、add、remove）。
4
基础去重统计

想统计"体温列表里有几种不同的温度"，最合适的是？

A. 手动数　　B. len(set(体温列表))　　C. len(体温列表)　　D. 体温列表.count(全部)

参考答案
B。set() 去重 → len() 数个数。len(列表) 是总数（含重复），不适用。

进阶题

5
进阶元组用途

下面哪种数据最适合用元组存？

A. 值班医生名单（每周变）　　B. 出生日期 (年, 月, 日)——永不改变　　C. 病人体温记录　　D. 药品库存

参考答案
B。元组 = "不该被改的数据"。出生日期是固定记录用元组；名单/体温/库存都要变，用列表。
6
进阶集合运算

a = {1, 2, 3}，b = {2, 3, 4}，a & b 的结果是？（& 是交集：两边都有）

A. {2, 3}　　B. {1, 2, 3, 4}　　C. {1, 4}　　D. 报错

参考答案
A。交集 & 取两边都有的元素：2 和 3 同时出现在两个集合里。集合天生支持数学运算（交集 &、并集 |、差集 -），处理"共同/去重"类问题很好用。

运用题

7
运用重复检查

住院号列表 ids = ["A001", "A002", "A001", "A003", "A002"]。写代码统计：① 一共有几条记录 ② 有几个不同病人。

提示：len() 总数，set() 去重后再 len()。

参考答案
ids = ["A001", "A002", "A001", "A003", "A002"]
print("总记录：", len(ids))          # 5
print("不同病人：", len(set(ids)))   # 3
自查要点：len(set(ids)) 是"去重后数个数"的标准组合，体检数据/病历数据查重复时很常用。
8
运用交集找药（填空）

药房 A 有 a = {"阿司匹林", "二甲双胍", "奥美拉唑"}，药房 B 有 b = {"二甲双胍", "硝苯地平"}。填空：找出两个药房都有的药。

a = {"阿司匹林", "二甲双胍", "奥美拉唑"}
b = {"二甲双胍", "硝苯地平"}
共同 = ____    # 填：求交集
print(共同)

提示：交集符号是 &。

参考答案
a = {"阿司匹林", "二甲双胍", "奥美拉唑"}
b = {"二甲双胍", "硝苯地平"}
共同 = a & b    # 交集
print(共同)     # {"二甲双胍"}
解析：集合的 & 直接求两边共有元素。"找两个名单的共同项"（共同病人、共同药物）用集合交集一行搞定。
