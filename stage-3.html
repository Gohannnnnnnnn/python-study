第 11 课 · py-011

元组与集合：容器家族新成员

知识要点

1. 元组 = 只读列表（() 创建）
元组和列表几乎一样（有顺序、能索引、能切片），唯一区别：创建后不能改——不能增、不能删、不能改值。 
坐标 = (3, 5)          # 圆括号 () 创建
病人 = ("张三", "男", "2026-08-01")
print(坐标[0])          # 3 —— 能查（索引和列表一样）
坐标[0] = 9             # ❌ 报错！元组不能修改
医生类比：列表是「值班表」（随时加人删人），元组是「病历上的出生日期」（录进去就不能改——固定记录）。
2. 集合 = 去重口袋（{} 无冒号）
集合三大特性：自动去重（重复只留一个）、无序（没有编号）、能增删（add / remove）。 
体温记录 = {37.2, 38.5, 37.2, 36.8}   # 花括号 {} 但里面没有冒号
print(体温记录)   # {36.8, 37.2, 38.5} —— 37.2 只出现一次！

名单 = {"张三", "李四"}
名单.add("王五")        # 加一个
名单.add("张三")        # 已有 → 不重复加
名单.remove("李四")     # 删一个
医生类比：集合是「住院号登记本」——同一个病人挂几次号，登记本上只有一个号。
3. 容器家族全家福
容器符号顺序能改按键找去重
列表 list[]✅✅编号❌
元组 tuple()✅❌编号❌
字典 dict{} 键:值✅✅键键去重
集合 set{} 无冒号❌✅❌✅
记忆口诀：列表能改有顺序，元组只读有顺序，字典按键找值，集合自动去重。
4. 实战：统计不同种类
体温列表 = [37.2, 38.5, 37.2, 36.8, 38.5]
种类数 = len(set(体温列表))     # 列表转集合 → 去重 → 数个数
print("不同体温种类：", 种类数, "种")   # 3 种
set(列表) 把列表变成集合自动去重，len() 数个数——这是统计"有几种"的标准姿势。
一句话总结：元组是只读列表（防误改），集合是去重口袋（无序、无编号）——"能按编号取"的前提是有顺序，集合为了去重牺牲了顺序。

第 12 课 · py-012

字符串方法：处理文本的瑞士军刀

知识要点

1. strip / upper / lower——清理与大小写
姓名 = "  Zhang San  "        # 注意前后有空格
print(姓名.strip())            # "Zhang San" —— 去掉首尾空白
print(姓名.upper())            # "  ZHANG SAN  " —— 全大写
print(姓名.strip().lower())    # "zhang san" —— 链式调用
医生场景：用户输入姓名带空格（" 张三 "），`姓名.strip()` 一步清理干净。
2. split / join——拆分与拼接（方向相反）
体温记录 = "37.2, 38.5, 36.8"
列表 = 体温记录.split(", ")     # ["37.2", "38.5", "36.8"] —— 拆成列表
新字符串 = " | ".join(列表)     # "37.2 | 38.5 | 36.8" —— 拼回字符串
注意 join 写法反直觉：`"分隔符".join(列表)`——胶水在前，列表在后。
3. ⚠️ 字符串不可变——所有方法都是"复印机"
s = "abc"
s[0] = "X"       # ❌ 报错！字符串不能改
s.upper()        # 产生 "ABC" 但没存 → 丢了
新 = s.upper()   # ✅ 必须接住返回值
print(s)         # 还是 "abc"（原件从未被改动）
心智模型：字符串方法像"复印机"——返回新值、原件不动。不接住 = 白复印。列表方法（append/remove）是直接改原件，字符串方法是返回新值，两者完全不同。
一句话总结：strip/split/join 是文本处理三件套；字符串方法都是"复印机"——返回新值、原件不动，必须接住返回值。

第 13 课 · py-013

嵌套结构：真实数据的形状

知识要点

1. 列表套列表 = 表格（[行][列]）
体温记录 = [
    ["张三", 38.5],
    ["李四", 37.2],
]
print(体温记录[0])      # ['张三', 38.5] —— 第一行
print(体温记录[0][0])   # 张三 —— 第一行第0列
print(体温记录[1][1])   # 37.2 —— 第二行第1列
底层逻辑：两次取号，先外后内——像档案柜的抽屉里还有小格子。`[行号][列号]`。
2. 列表套字典 = 一摞病历卡（最常用）
病人列表 = [
    {"姓名": "张三", "体温": 38.5, "诊断": "肺炎"},
    {"姓名": "李四", "体温": 37.2, "诊断": "待查"},
]
print(病人列表[0]["姓名"])   # 张三 —— 第0张卡的"姓名"
for 病人 in 病人列表:
    print(病人["姓名"], 病人["体温"])   # 遍历所有病人
取值口诀：`[编号]` 抽卡 → `["键"]` 看字段。这就是 py-010 候诊系统的结构。
3. 字典套字典 = 层级数据（两级查找）
患者档案 = {
    "张三": {"体温": 38.5, "诊断": "肺炎"},
    "李四": {"体温": 37.2, "诊断": "待查"},
}
print(患者档案["张三"]["诊断"])   # 肺炎 —— 先外层键，再内层键
重要：API 返回的 JSON 全是这种结构。学会嵌套 = 学会读 JSON——调 DeepSeek API、处理文献数据全靠它。
一句话总结：嵌套取值像剥洋葱——先剥外层再剥里层；列表套字典（一摞病历卡）是"先抽卡、再看字段"；学会嵌套就读得懂 JSON。

第 14 课 · py-014

阶段综合演练：病人数据管理系统

知识要点

1. 全系统代码（元组 + 嵌套 + strip + 集合 + 遍历）
医院 = ("阜阳市人民医院", "胸外科", "v1.0")   # 元组：固定信息
print("系统：", 医院[0], "-", 医院[1], "版本", 医院[2])

病人列表 = [                                # 嵌套：一摞病历卡
    {"姓名": "张三", "体温": 38.5, "诊断": "肺炎"},
    {"姓名": "李四", "体温": 37.2, "诊断": "支气管炎"},
    {"姓名": "王五", "体温": 36.8, "诊断": "肺炎"},
]

新病人 = input("新病人姓名：").strip()        # strip：清理输入

for 病人 in 病人列表:                        # 遍历 + 统计
    print(病人["姓名"], 病人["体温"], "度", 病人["诊断"])

诊断列表 = [病人["诊断"] for 病人 in 病人列表]  # 列表推导式：收集所有诊断
print("诊断种类：", len(set(诊断列表)), "种")    # 集合：去重统计

for 病人 in 病人列表:                        # 筛选急症
    if 病人["体温"] >= 38:
        print("急症：", 病人["姓名"])
2. 五个零件各管一件事
零件作用来自哪课
元组 ()存固定信息（防误改）py-011
strip()清理用户输入的空格py-012
列表推导式一行收集数据（= for+append 简写）py-014 初见
set()去重统计种类py-011
嵌套结构存多条记录（列表套字典）py-013
一句话总结：病人数据管理系统 = 元组管"不变的" + 嵌套管"数据的形状" + strip 管"输入干净" + 集合管"统计去重"——四个知识点组装成一个真实系统。

第 15 课 · py-015

字符串更多方法：查、换、数、判

知识要点

1. find——找位置（找不到返回 -1）
病历 = "患者张三，体温38.5度，诊断为肺炎"
位置 = 病历.find("肺炎")
print(位置)          # 15 —— 从 0 数
print(病历[位置:])   # 肺炎 —— 切片取出
print(病历.find("肺癌"))   # -1 —— 找不到！注意不是报错
标志性行为：找不到返回 -1。写代码常用 if 位置 != -1: 判断"有没有找到"。
2. replace——替换（复印机！必须接住）
报告 = "患者体温38.5度，体温偏高"
新报告 = 报告.replace("38.5", "38.2")
print(新报告)   # 患者体温38.2度，体温偏高
print(报告)     # 原字符串没变！（复印机）
报告.replace("体温", "体温计", 1)   # 第三参数=替换几次
3. count / startswith——数次数与判格式
医嘱 = "每天3次，每次2片，饭后服用，共7天"
print(医嘱.count("次"))    # 2

住院号 = "A20260902"
print(住院号.startswith("A"))   # True —— 格式检查
文件名 = "data.csv"
if 文件名.endswith(".csv"):
    print("是 CSV 文件")
一句话总结：find 找位置（找不到是 -1 不是报错）、replace 换内容（复印机必须接住）、count 数次数、startswith 判格式——四个方法搞定 90% 文本处理。

第 16 课 · py-016

字典高级：get / setdefault / 嵌套遍历

知识要点

1. get——安全取值（键不存在不报错）
患者 = {"姓名": "张三", "体温": 38.5}
print(患者["诊断"])          # ❌ KeyError！键不存在直接崩
print(患者.get("诊断"))       # None —— 不报错
print(患者.get("诊断", "无")) # "无" —— 给默认值
三档对比：[] 报错 / get 给 None / get+默认 给兜底。处理 API 返回的 JSON 时字段常缺失——get 是写健壮代码的第一课。
2. setdefault——"有就用，没有就创建"
统计 = {}
统计.setdefault("发热", 0)   # 不存在 → 创建并设 0
统计.setdefault("发热", 0)   # 已存在 → 不动
统计["发热"] = 统计["发热"] + 1
print(统计)                 # {'发热': 1}
用途：统计各诊断的病人数——第一次见"肺炎"就建计数器，之后累加。setdefault(键, 默认) = "自动建计数器"。
3. 嵌套字典遍历——两层结构两层循环
病房 = {
    "101室": {"张三": 38.5, "李四": 37.2},
    "102室": {"王五": 39.0},
}
for 房号, 病人体温 in 病房.items():
    for 病人, 体温 in 病人体温.items():
        print(房号, 病人, 体温, "度")
底层逻辑：items() 递出键+值，值又是字典——内层再套 for。两层结构 = 两层循环（py-013 学过）。
一句话总结：get 是安全取值（有键用真值、没键用默认）、setdefault 是自动建计数器、嵌套字典用双层循环遍历。
